## Web ইনস্টলেশন উইজার্ড (সুপারিশকৃত)

প্রজেক্টে বিল্ট-ইন Web ইনস্টলেশন উইজার্ড আছে, অ্যাডমিন প্যানেল চালু করার পর ব্রাউজার দিয়ে সম্পূর্ণ কনফিগারেশন করা যায়।

### ব্যবহারের ধাপ

```bash
# 1. অ্যাডমিন ডিরেক্টরিতে যান
cd admin

# 2. এনভায়রনমেন্ট ভেরিয়েবল ফাইল তৈরি (টেমপ্লেট থেকে কপি)
cp .env.example .env

# 3. ডিপেন্ডেন্সি ইনস্টল
composer install --no-dev --optimize-autoloader

# 4. সার্ভিস চালু করুন
php start.php start -d
```

### 5. ইনস্টলেশন উইজার্ড খুলুন

ব্রাউজারে **`http://localhost:8787/install`** অ্যাক্সেস করুন, প্রম্পট অনুযায়ী তিন ধাপের কনফিগারেশন সম্পন্ন করুন:

| ধাপ | বিষয়বস্তু | ব্যাখ্যা |
|------|------|------|
| ১ম ধাপ | ডেটাবেস কনফিগারেশন | হোস্ট, পোর্ট, ডেটাবেস নাম, ইউজারনেম, পাসওয়ার্ড লিখুন |
| ২য় ধাপ | অ্যাডমিন অ্যাকাউন্ট | ব্যাকএন্ড লগইন ইউজারনেম ও পাসওয়ার্ড সেট করুন (অন্তত ৬ অক্ষর) |
| ৩য় ধাপ | ইনস্টলেশন নিশ্চিতকরণ | কনফিগ তথ্য মিলিয়ে দেখুন, নিশ্চিত ক্লিক করলে স্বয়ংক্রিয়ভাবে ইনস্টলেশন চলে |

ইনস্টলেশন প্রক্রিয়া স্বয়ংক্রিয়ভাবে সম্পন্ন করে:
1. ডেটাবেস কানেকশন পরীক্ষা
2. `.env` কনফিগ ফাইল লেখা
3. সম্পূর্ণ ৬৫টি ডেটা টেবিল + পারমিশন সিড ইমপোর্ট
4. অ্যাডমিন অ্যাকাউন্ট তৈরি ও সুপার অ্যাডমিন রোল প্রদান
5. ইনস্টলেশন লক ফাইল `public/.installed` তৈরি

### ইনস্টলেশন সম্পন্নের পরে

- অ্যাডমিন প্যানেল ঠিকানা: `http://localhost:8787/admin`
- ইনস্টলেশন উইজার্ড লগইন ঠিকানা ও অ্যাকাউন্ট তথ্য দেখাবে
- কনফিগ কার্যকর করতে সার্ভিস রিস্টার্টের পরামর্শ: `php start.php restart -d`
- পুনরায় ইনস্টল করতে চাইলে `public/.installed` ফাইল মুছে দিন

## ডেটাবেস ইনিশিয়ালাইজেশন

### 1. ডেটাবেস তৈরি

```bash
mysql -u root -p <<SQL
CREATE DATABASE IF NOT EXISTS management
  DEFAULT CHARSET utf8mb4
  COLLATE utf8mb4_unicode_ci;
SQL
```

### 2. একীভূত ইনস্টলেশন স্ক্রিপ্ট ইমপোর্ট

```bash
mysql -u root -p management < docs/install.sql
```

`docs/install.sql` সম্পূর্ণ ৬৫টি টেবিল + RBAC পারমিশন সিড ডেটা ধারণ করে, `CREATE TABLE IF NOT EXISTS` ব্যবহার করে পুনরাবৃত্তি নিরাপদ।

চালানোর পর যাচাই:

```bash
mysql -u root -p management -e "SHOW TABLES;" | wc -l
# আউটপুট হওয়া উচিত: 66 (৬৫টি টেবিল + ১ লাইন হেডার)
```

## অ্যাডমিন প্যানেল ডিপ্লয়মেন্ট

অ্যাডমিন প্যানেল `http://localhost:8787`-এ চলে, অ্যাডমিন ব্যাকএন্ড API প্রদান করে।

```bash
cd admin

# 1. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার
cp .env.example .env
# .env সম্পাদনা, ডেটাবেস পাসওয়ার্ড, JWT কী ইত্যাদি বদলান

# 2. ডিপেন্ডেন্সি ইনস্টল
composer install --no-dev --optimize-autoloader

# 3. সার্ভিস চালু করুন
php start.php start -d
# -d ব্যাকগ্রাউন্ডে চালানো বোঝায়, -d ছাড়া ফোরগ্রাউন্ডে চালিয়ে লগ দেখা যায়

# 4. যাচাই
curl http://localhost:8787/health
```

### মূল কনফিগ আইটেম (admin/.env)

| কনফিগ আইটেম | ব্যাখ্যা | প্রোডাকশন প্রয়োজনীয়তা |
|--------|------|-------------|
| `JWT_SECRET_KEY` | JWT সাইনিং কী | ৬৪ বিটের বেশি র্যান্ডম স্ট্রিং |
| `HASHIDS_SALT` | ID এনক্রিপশন সল্ট | র্যান্ডম স্ট্রিং, service-এর সাথে একই রাখুন |
| `SNOWFLAKE_DATACENTER_ID` | ডেটাসেন্টার ID (0-31) | মাল্টি-ডেটাসেন্টার ডিপ্লয়মেন্টে আলাদা করতে হবে |
| `SNOWFLAKE_WORKER_ID` | ওয়ার্কার নোড ID (0-31) | একই ডেটাসেন্টারে প্রতি মেশিনে আলাদা |
| `ENCRYPTION_KEY` | API ট্রান্সমিশন এনক্রিপশন কী | ৩২ বাইট র্যান্ডম স্ট্রিং |
| `ENCRYPTABLE_KEY` | ডেটাবেস ফিল্ড এনক্রিপশন কী | ৩২ বাইট র্যান্ডম স্ট্রিং |
| `DB_PASSWORD` | ডেটাবেস পাসওয়ার্ড | শক্তিশালী পাসওয়ার্ড |

## ব্যবসা পাশ ডিপ্লয়মেন্ট

ব্যবসা পাশ `http://localhost:8788`-এ চলে, মালিক পাশ API প্রদান করে।

```bash
cd service

# 1. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার
cp .env.example .env
# .env সম্পাদনা, ডেটাবেস পাসওয়ার্ড, JWT কী ইত্যাদি বদলান

# 2. ডিপেন্ডেন্সি ইনস্টল
composer install --no-dev --optimize-autoloader

# 3. সার্ভিস চালু করুন
php start.php start -d

# 4. যাচাই
curl http://localhost:8788/health
```

> **লক্ষ্য:** admin ও service একই ডেটাবেস শেয়ার করে। `HASHIDS_SALT` অবশ্যই admin-এর সাথে একই রাখতে হবে, অন্যথায় admin-এ তৈরি এনক্রিপ্টেড ID service পাশে ডিক্রিপ্ট করা যাবে না।

## Docker ডিপ্লয়মেন্ট

### অ্যাডমিন প্যানেল

```bash
cd admin
cp .env.docker .env
# .env সম্পাদনা করে প্রোডাকশন কী বদলান

docker compose up -d
# অন্তর্ভুক্ত: Nginx + PHP + MySQL + Redis + Elasticsearch
```

### ব্যবসা পাশ

```bash
cd service
cp .env.docker .env
# .env সম্পাদনা করে প্রোডাকশন কী বদলান

docker compose up -d
```

### সার্ভিস পোর্ট পরিকল্পনা

| সার্ভিস | admin | service | ব্যাখ্যা |
|------|-------|---------|------|
| অ্যাপ্লিকেশন | 8787 | 8788 | webman HTTP |
| MySQL | 3306 | 3307 | কন্টেইনার পোর্ট ম্যাপিং |
| Redis | 6379 | 6380 | কন্টেইনার পোর্ট ম্যাপিং |
| Elasticsearch | 9200 | 9201 | কন্টেইনার পোর্ট ম্যাপিং |
| Nginx | 80/443 | 80/443 | আলাদা করে ডিপ্লয় করতে হবে |

> একই হোস্টে দুটি docker-compose ডিপ্লয় করলে, service-এর পোর্ট অফসেট প্রিসেট করা আছে সংঘর্ষ এড়াতে।

## ইনস্টলেশন যাচাই

### 1. হেলথ চেক

```bash
# অ্যাডমিন প্যানেল
curl http://localhost:8787/health

# ব্যবসা পাশ
curl http://localhost:8788/health
```

### 2. API ডকুমেন্টেশন

সম্পূর্ণ API এন্ডপয়েন্ট ও প্যারামিটার ব্যাখ্যা আলাদা ডকুমেন্ট [API.md](API.md)-এ। সার্ভিস চালু হলে স্বয়ংক্রিয়ভাবে তৈরি ইন্টারঅ্যাক্টিভ ইন্টারফেস ডকুমেন্টও অ্যাক্সেস করা যায়:

| পাশ | ঠিকানা |
|----|------|
| অ্যাডমিন প্যানেল | http://localhost:8787/apidoc |
| ব্যবসা পাশ | http://localhost:8788/apidoc |

### 3. লগইন টেস্ট

```bash
curl -X POST http://localhost:8787/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

### 4. টেস্ট চালানো

```bash
# অ্যাডমিন প্যানেল
cd admin && php vendor/bin/phpunit

# ব্যবসা পাশ
cd service && php vendor/bin/phpunit
```

## সাধারণ সমস্যা

### Q: স্টার্টআপে এরে `Call to undefined function pcntl_fork()`

PHP-তে pcntl এক্সটেনশন নেই।

```bash
# Ubuntu/Debian
apt install php-pcntl

# Docker
docker-php-ext-install pcntl
```

### Q: লগইনের পর Token অবৈধ দেখায়

admin ও service-এর `.env`-এ নিচের কনফিগ একই আছে কিনা পরীক্ষা করুন:
- `JWT_SECRET_KEY`
- `JWT_ALGORITHM`

### Q: এনক্রিপ্টেড ID দুই পাশে আলাদা

admin ও service-এর `HASHIDS_SALT` মান সম্পূর্ণ একই নিশ্চিত করুন।

### Q: Docker কন্টেইনারগুলোর মধ্যে নেটওয়ার্ক চলছে না

IP-র বদলে কন্টেইনার নাম দিয়ে কানেক্ট করুন (যেমন `DB_HOST=mysql`)।

### Q: কীভাবে ডেটাবেস রিসেট করবেন

```bash
mysql -u root -p -e "DROP DATABASE IF EXISTS management;"
mysql -u root -p -e "CREATE DATABASE management DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p management < docs/install.sql
```

### Q: কীভাবে HTTPS কনফিগার করবেন

প্রোডাকশনে Nginx রিভার্স প্রক্সি দিয়ে TLS টার্মিনেট করার পরামর্শ। রেফারেন্স কনফিগ দেখুন `admin/docs/nginx-security.conf`।
