## ফাংশন মডিউল তুলনা

### বেসিক (Lite)

কোর সম্পত্তি ব্যবস্থাপনা, অ্যাডমিন প্যানেল সাধারণ সিস্টেম + ১০টি কোর বিজনেস মডিউল সহ।

**অ্যাডমিন প্যানেল**: ড্যাশবোর্ড, ব্যবহারকারী/ভূমিকা/অনুমতি/কনফিগ/লগ CRUD, কমিউনিটি/ভবন/ইউনিট/রুমের ধরন/সম্পত্তি/মালিক/ভাড়াটে/ফি/মেরামত/ঘোষণা CRUD

**মালিক পোর্টাল**: রেজিস্ট্রেশন/লগইন, হোমপেজ, আমার সম্পত্তি, বিল ফি পরিশোধ, মেরামত জমা/রেটিং, ঘোষণা দেখা, ব্যক্তিগত তথ্য

---

### স্ট্যান্ডার্ড (Standard)

বেসিক-এর উপরে ৬টি সহায়ক বিজনেস মডিউল + প্যানেল ভিজ্যুয়ালাইজেশন + ডেটা এক্সপোর্ট যোগ করে।

**অ্যাডমিন প্যানেলে নতুন**: পার্কিং স্পট/যানবাহন CRUD, যন্ত্রপাতি লেজার+রক্ষণাবেক্ষণ, অভিযোগ প্রক্রিয়াকরণ+ফলো-আপ, দর্শনার্থী অনুমোদন, চুক্তি ব্যবস্থাপনা, আয়-ব্যয় ব্যবস্থাপনা+পরিসংখ্যান

**মালিক পোর্টালে নতুন**: আমার যানবাহন/পার্কিং স্পট, পার্কিং রেকর্ড, দর্শনার্থী অ্যাপয়েন্টমেন্ট/প্রবেশ কোড

---

### সম্পূর্ণ (Full)

স্ট্যান্ডার্ড-এর উপরে অ্যাডভান্সড মডিউল + ১২টি এক্সটেনশন ফিচার যোগ করে।

**অ্যাডমিন প্যানেলে নতুন**: টহল রুট+রেকর্ড, পরিচ্ছন্নতা এলাকা+রেকর্ড, বাগান এলাকা+যত্ন, কমিউনিটি কার্যক্রম ব্যবস্থাপনা, শক্তি মিটার+রিডিং, কর্মচারী ব্যবস্থাপনা, বিজ্ঞপ্তি টেমপ্লেট+পাঠানো, অনুমোদন ইঞ্জিন, পেমেন্ট অর্ডার+রিফান্ড, ভোট ব্যবস্থাপনা+SLA নিয়ম+আদায় কৌশল+পরিদর্শন টাস্ক+মল ব্যবস্থাপনা+ফেসিয়াল পর্যালোচনা+গ্রুপ ব্যবস্থাপনা+জ্ঞানভাণ্ডার

**মালিক পোর্টালে নতুন**: কমিউনিটি কার্যক্রমে নিবন্ধন, পার্কিং/দর্শনার্থী অ্যাপয়েন্টমেন্ট, বার্তা বিজ্ঞপ্তি, ভোট+ভোট গণনা, পণ্য ব্রাউজ+অর্ডার, স্মার্ট Q&A, ফেসিয়াল রেজিস্ট্রেশন

## নিরাপত্তা ব্যবস্থা (তিন সংস্করণে সাধারণ)

১৮ স্তরের গভীর প্রতিরক্ষা: ক্যাপচা → পাসওয়ার্ড নিশ্চিতকরণ → র্যান্ডম যাচাই → নিরাপত্তা স্ক্যান → আক্রমণ ব্লক → HTTPS + AES-256-CBC → JWT → সেশন নিয়ন্ত্রণ → অ্যাকাউন্ট লক → RBAC → রেট লিমিট → ID সুরক্ষা → রিকোয়েস্ট এনক্রিপশন → স্টোরেজ এনক্রিপশন → ডিসপ্লে মাস্কিং → অডিট → CSP → কপিরাইট ওয়াটারমার্ক

## ডেমো প্রক্রিয়া

**প্রস্তুতি**: `docs/install.sql` চালানো হয়েছে (সম্পূর্ণ টেবিল কাঠামো, সব সংস্করণের টেবিল সহ); `admin/.env`-এ ডেটাবেস সংযোগ কনফিগার করা আছে। সংস্করণ পার্থক্য রুট রেজিস্ট্রেশন ও ফাংশন দৃশ্যমানতায়; টেবিল কাঠামো সবসময় সম্পূর্ণ।

### বেসিক (Lite)

1. ডেমো ডেটা চালান: `cd admin && php ../scripts/demo_data.php` (আইডেমপোটেন্ট, বারবার চালানো যায়)
2. ডেমো ডেটা পরিসর: কমিউনিটি/ভবন/ইউনিট/রুমের ধরন/সম্পত্তি/মালিক/ভাড়াটে/ফি/বিল/ঘোষণা + ডেমো অ্যাকাউন্ট, Lite কোর মডিউল কভার করে
3. কী দেখবেন: অ্যাডমিন প্যানেল ড্যাশবোর্ড + ব্যবহারকারী/ভূমিকা/অনুমতি/কনফিগ/লগ + সম্পত্তি/মালিক/ভাড়াটে/ফি/মেরামত/ঘোষণা CRUD; মালিক পোর্টালে রেজিস্ট্রেশন/লগইন, হোমপেজ, আমার সম্পত্তি, বিল ফি পরিশোধ, মেরামত, ঘোষণা
4. রুট পার্থক্য: শুধুমাত্র Lite গ্রুপ নিবন্ধিত, `edition_supports('standard'/'full')` দিয়ে ঘেরা ব্লক নিবন্ধিত হয় না (`admin/config/route.php`)

### স্ট্যান্ডার্ড (Standard)

1. ডেমো ডেটা চালান: `cd admin && php ../scripts/demo_data.php` (আইডেমপোটেন্ট, বারবার চালালে শুধু ঘাটতি পূরণ হয়, ডুপ্লিকেট তৈরি হয় না)
2. সহায়ক মডিউলের ডেটা কম, পার্কিং/যন্ত্রপাতি/অভিযোগ/দর্শনার্থী/চুক্তি/আয়-ব্যয় ডেমোতে অল্প লিখলেই চলবে
3. কী দেখবেন: অ্যাডমিন প্যানেলে নতুন পার্কিং স্পট/যানবাহন, যন্ত্রপাতি লেজার+রক্ষণাবেক্ষণ, অভিযোগ প্রক্রিয়াকরণ+ফলো-আপ, দর্শনার্থী অনুমোদন, চুক্তি ব্যবস্থাপনা, আয়-ব্যয় ব্যবস্থাপনা+পরিসংখ্যান; মালিক পোর্টালে নতুন আমার যানবাহন/পার্কিং স্পট, পার্কিং রেকর্ড, দর্শনার্থী অ্যাপয়েন্টমেন্ট/প্রবেশ কোড
4. রুট পার্থক্য: `edition_supports('standard')` গ্রুপ যুক্ত হয়, Lite গ্রুপ রয়ে যায়

### সম্পূর্ণ (Full)

1. ডেমো ডেটা চালান: `cd admin && php ../scripts/demo_data.php` (আইডেমপোটেন্ট)
2. অ্যাডভান্সড মডিউল (পেমেন্ট/অনুমোদন/ভোট/মল/পরিদর্শন/ফেসিয়াল/গ্রুপ/জ্ঞানভাণ্ডার) ডেমো ডেটা প্রয়োজন অনুযায়ী লিখুন, বা ডেমো অ্যাকাউন্ট দিয়ে সরাসরি ডেটা তৈরি করুন
3. কী দেখবেন: Standard-এর উপরে নতুন টহল/পরিচ্ছন্নতা/বাগান/শক্তি/কর্মচারী/বিজ্ঞপ্তি টেমপ্লেট/অনুমোদন ইঞ্জিন/পেমেন্ট অর্ডার/ভোট/SLA/আদায়/পরিদর্শন/মল/ফেসিয়াল/গ্রুপ/জ্ঞানভাণ্ডার; মালিক পোর্টালে কার্যক্রমে নিবন্ধন, বার্তা বিজ্ঞপ্তি, ভোট, মলে অর্ডার, স্মার্ট Q&A, ফেসিয়াল রেজিস্ট্রেশন
4. রুট পার্থক্য: সম্পূর্ণ নিবন্ধন, `edition_supports('full')` গ্রুপ কার্যকর (`admin/config/route.php`)

### সংস্করণ পরিবর্তন

```bash
# admin/.env-এ টার্গেট সংস্করণ সেট করুন (ক্রমবর্ধমান, full-এ সব ফাংশন থাকে)
EDITIONS=lite|standard|full

# webman রিস্টার্ট করে কার্যকর করুন (কন্টেইনার ডিপ্লয়মেন্ট: docker compose restart app; বেয়ার মেটাল: php start.php restart)
```

- কনফিগ fail-fast: `EDITIONS` মান অবৈধ হলে সরাসরি এরর (`admin/config/edition.php`), নীরবে ভুল সংস্করণে ফলব্যাক হয় না।
- ডেমো ডেটা স্ক্রিপ্ট আইডেমপোটেন্ট, সংস্করণ পরিবর্তনে ডেটাবেস মুছতে হয় না; Standard/Full মডিউলের ডেটা কম, আসল ব্যবসা দিয়ে লিখলেই চলবে।
