## ক্রস-ফাংশনাল ফিচার

### ID এনক্রিপ্টেড ট্রান্সমিশন
সব API ইন্টারফেসের রিকোয়েস্ট ও রেসপন্সের ID ফিল্ড `erikwang2013/hashids` দিয়ে এনকোড/ডিকোড হয়। ক্লায়েন্ট hashid স্ট্রিং (যেমন `aB3xK9mW2pQ7rT5v`) পায়, ব্যাকএন্ড BIGINT-এ ডিকোড করে অপারেশন চালায়।

### সংবেদনশীল ডেটা সুরক্ষা
- API ট্রান্সমিশন লেয়ার: `erikwang2013/encryption` — AES-256-CBC
- ডেটাবেস স্টোরেজ লেয়ার: `erikwang2013/encryptable` — Eloquent Model casts স্বয়ংক্রিয় এনক্রিপশন/ডিক্রিপশন
- ফ্রন্টএন্ড ডিসপ্লে লেয়ার: মোবাইল নম্বর 138****1234, ইমেইল a***@e.com

### অপারেশন অডিট
অ্যাডমিন প্যানেলের সব POST/PUT/DELETE অপারেশন স্বয়ংক্রিয়ভাবে রেকর্ড হয়, যার মধ্যে অপারেটিং ব্যবহারকারী, IP, পথ, প্যারামিটার (মাস্ক করা), অপারেশন সময়, উৎস (web/ios/android/harmonyos/windows/macos/linux/ipados)।

### অনুমতি নিয়ন্ত্রণ
- অ্যাডমিন প্যানেল: RBAC method.path গ্রানুলার অথরাইজেশন, সুপার অ্যাডমিন `*` চেক স্কিপ করে
- মালিক পোর্টাল: JWT Bearer টোকেন প্রমাণীকরণ, মালিক শুধুমাত্র নিজের ডেটা পরিচালনা করতে পারে

### নিরাপত্তা সুরক্ষা
১৮ স্তরের গভীর প্রতিরক্ষা: ক্যাপচা → পাসওয়ার্ড নিশ্চিতকরণ → র্যান্ডম যাচাই → নিরাপত্তা স্ক্যান → আক্রমণ ব্লক → ট্রান্সমিশন এনক্রিপশন → JWT → সেশন নিয়ন্ত্রণ → অ্যাকাউন্ট লক → RBAC → রেট লিমিট → ID সুরক্ষা → রিকোয়েস্ট এনক্রিপশন → স্টোরেজ এনক্রিপশন → ডিসপ্লে মাস্কিং → অডিট → CSP → কপিরাইট ওয়াটারমার্ক

### এক্সপোর্ট ফাংশন
- Excel: PhpSpreadsheet, নীল ব্যাকগ্রাউন্ড সাদা টেক্সট হেডার + প্রথম সারি ফ্রিজ + অটো ফিল্টার + সংবেদনশীল ডেটা মাস্কিং
- PDF: Dompdf A4 ল্যান্ডস্কেপ, পেজ হেডারে কপিরাইট + পেজ ফুটারে অপসারণযোগ্য নয় এমন কপিরাইট ওয়াটারমার্ক
- প্যানেল ভিজ্যুয়ালাইজেশন ডেটা PDF এক্সপোর্ট

### সার্চ ইঞ্জিন
- `erikwang2013/webman-scout` Elasticsearch চালায়
- স্বয়ংক্রিয় ইনডেক্স সিঙ্ক (যোগ/পরিবর্তন/মুছলে অটো পুশ)
- ইনডেক্স প্রিফিক্স `management_`, ডেটাবেস টেবিল প্রিফিক্সের সাথে সামঞ্জস্যপূর্ণ

### আন্তর্জাতিকীকরণ (i18n)
- **PHP ব্যাকএন্ড**: symfony/translation — `resource/translations/{zh_CN,en}/messages.php`, ৪২টি ট্রান্সলেশন কী, কন্ট্রোলার `__()` মেথড দিয়ে ট্রান্সলেশন পায়
- **Flutter Web**: GetX `Translations` — `lib/i18n/messages.dart`, ১০১টি ট্রান্সলেশন কী, পেজ `.tr` এক্সটেনশন দিয়ে ব্যবহার করে
- **HarmonyOS**: `resources/{base,en_US}/element/string.json` রিসোর্স কোয়ালিফায়ার
- **ডিফল্ট ভাষা**: সরলীকৃত চীনা (zh_CN), ফলব্যাক ভাষা ইংরেজি (en)
- **রিকোয়েস্ট হেডার**: `Accept-Language` দিয়ে রেসপন্স ভাষা নিয়ন্ত্রণ সমর্থিত

- **TDD প্রক্রিয়া**: লাল→সবুজ→রিফ্যাক্টর, প্রথমে টেস্ট পরে কোড
- **অ্যাডমিন প্যানেল**: ৬০টি টেস্ট, ১৬৪টি অ্যাসারশন, বেস সার্ভিস, পরিবেশ কনফিগারেশন, নিরাপত্তা যাচাই কভার করে
- **মালিক পোর্টাল**: ১৮টি টেস্ট, ৪৫টি অ্যাসারশন, ১০০% পাস রেট
- **মোট**: ৭৮টি টেস্ট, ২০৯টি অ্যাসারশন
- **কভারেজ পরিসর**: Snowflake ID তৈরি ইউনিকনেস, Hashids এনকোড/ডিকোড রাউন্ডট্রিপ, ইউনিফাইড রেসপন্স ফরম্যাট, ৬৪টি টেবিল Schema যাচাই, চীনা-ইংরেজি ট্রান্সলেশন কী সামঞ্জস্য
- **Flutter**: flutter analyze শূন্য সমস্যা
- **API ডকুমেন্টেশন**: `hg/apidoc` স্বয়ংক্রিয় তৈরি, admin (১০ গ্রুপ) + service (৯ গ্রুপ), ফাংশন মডিউল অনুযায়ী ইন্টারফেস ডকুমেন্টেশন সংগঠিত
