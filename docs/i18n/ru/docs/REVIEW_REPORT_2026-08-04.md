## 3. Нерешённые проблемы

### 3.1 Высокая — уязвимости зависимостей

См. раздел 1.3. Исправление командами:

```bash
cd admin && composer update
cd ../service && composer update
```

### 3.2 Средняя — Redis без пароля

В `docker-compose.yml` у Redis не задан `requirepass`. Рекомендация:

```yaml
redis:
  command: redis-server --requirepass ${REDIS_PASSWORD:-change-me-redis-password}
```

### 3.3 Средняя — Docker-контейнеры работают от root

В `Dockerfile` нет инструкции `USER`:

```dockerfile
RUN addgroup -S app && adduser -S app -G app
USER app
```

### 3.4 Низкая — нет конфигурации Dependabot

Рекомендуется добавить `.github/dependabot.yml`:

```yaml
version: 2
updates:
  - package-ecosystem: "composer"
    directory: "/admin"
    schedule:
      interval: "weekly"
  - package-ecosystem: "composer"
    directory: "/service"
    schedule:
      interval: "weekly"
```

### 3.5 Низкая — у service нет конфигурации безопасности nginx

Каталога `service/docs/` нет. Рекомендуется скопировать и адаптировать `admin/docs/nginx-security.conf`.

### 3.6 Рекомендация — CSP unsafe-inline

Текущий CSP содержит `'unsafe-inline'` (зависит Flutter Web). В перспективе можно перейти на механизм nonce.

### 3.7 Рекомендация — проверка входных схем

Контроллеры берут значения напрямую через `$request->input()`, без структурной проверки. Рекомендуется добавить правила Validator в ключевые интерфейсы.
