## Web-мастер установки (рекомендуется)

В проект встроен Web-мастер установки: после запуска админ-панели вся настройка выполняется через браузер.

### Шаги использования

```bash
# 1. Перейти в каталог админ-панели
cd admin

# 2. Создать файл переменных окружения (копия из шаблона)
cp .env.example .env

# 3. Установить зависимости
composer install --no-dev --optimize-autoloader

# 4. Запустить сервис
php start.php start -d
```

### 5. Открыть мастер установки

В браузере перейти на **`http://localhost:8787/install`** и выполнить три шага настройки:

| Шаг | Содержание | Описание |
|------|------|------|
| Шаг 1 | Конфигурация БД | указать хост, порт, имя базы, пользователя и пароль |
| Шаг 2 | Учётная запись администратора | задать имя пользователя и пароль для входа в админ-панель (не менее 6 символов) |
| Шаг 3 | Подтверждение установки | проверить данные конфигурации, после подтверждения установка выполнится автоматически |

В процессе установки автоматически выполняются:
1. Проверка соединения с БД
2. Запись конфигурационного файла `.env`
3. Импорт всех 65 таблиц + начальных данных RBAC
4. Создание учётной записи администратора с ролью супер-администратора
5. Создание файла блокировки установки `public/.installed`

### После завершения установки

- Адрес админ-панели: `http://localhost:8787/admin`
- Мастер установки покажет адрес входа и данные учётной записи
- Рекомендуется перезапустить сервис, чтобы конфигурация вступила в силу: `php start.php restart -d`
- Для повторной установки достаточно удалить файл `public/.installed`

## Ручная установка

### Требования к окружению

| Компонент | Требование к версии | Описание |
|------|---------|------|
| PHP | 8.1+ (рекомендуется 8.3) | требуются расширения pcntl, pdo_mysql, redis, gd, mbstring |
| MySQL | 8.0+ | кодировка utf8mb4 |
| Redis | 6.0+ | кэш, ограничение частоты, Session |
| Composer | 2.x | управление PHP-зависимостями |
| Elasticsearch | 8.x | полнотекстовый поиск (опционально, при отключении используется запрос к БД) |
| Flutter SDK | 3.x | требуется только для разработки фронтенда |

### Проверка расширений PHP

```bash
php -m | grep -E "pcntl|pdo_mysql|redis|gd|mbstring|curl|json|xml|dom"
```

## Инициализация базы данных

### 1. Создание базы данных

```bash
mysql -u root -p <<SQL
CREATE DATABASE IF NOT EXISTS management
  DEFAULT CHARSET utf8mb4
  COLLATE utf8mb4_unicode_ci;
SQL
```

### 2. Импорт объединённого скрипта установки

```bash
mysql -u root -p management < docs/install.sql
```

`docs/install.sql` содержит все 65 таблиц + начальные данные RBAC, использует `CREATE TABLE IF NOT EXISTS` для повторяемого выполнения.

Проверка после выполнения:

```bash
mysql -u root -p management -e "SHOW TABLES;" | wc -l
# Должно вывести: 66 (65 таблиц + 1 строка заголовка)
```

## Развёртывание админ-панели

Админ-панель работает на `http://localhost:8787` и предоставляет API администратора.

```bash
cd admin

# 1. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env: изменить пароль БД, ключи JWT и т.д.

# 2. Установить зависимости
composer install --no-dev --optimize-autoloader

# 3. Запустить сервис
php start.php start -d
# -d — фоновый режим; без -d — запуск на переднем плане для просмотра логов

# 4. Проверка
curl http://localhost:8787/health
```

### Ключевые параметры конфигурации (admin/.env)

| Параметр | Описание | Требования для прода |
|--------|------|-------------|
| `JWT_SECRET_KEY` | ключ подписи JWT | случайная строка от 64 символов |
| `HASHIDS_SALT` | соль шифрования ID | случайная строка, должна совпадать с service |
| `SNOWFLAKE_DATACENTER_ID` | ID центра обработки данных (0-31) | различать при мультидата-центровом развёртывании |
| `SNOWFLAKE_WORKER_ID` | ID рабочего узла (0-31) | у каждой машины в одном ЦОД свой |
| `ENCRYPTION_KEY` | ключ шифрования передачи API | случайная строка 32 байта |
| `ENCRYPTABLE_KEY` | ключ шифрования полей БД | случайная строка 32 байта |
| `DB_PASSWORD` | пароль БД | надёжный пароль |

## Развёртывание портала жильцов

Портал жильцов работает на `http://localhost:8788` и предоставляет API владельцев.

```bash
cd service

# 1. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env: изменить пароль БД, ключи JWT и т.д.

# 2. Установить зависимости
composer install --no-dev --optimize-autoloader

# 3. Запустить сервис
php start.php start -d

# 4. Проверка
curl http://localhost:8788/health
```

> **Внимание:** admin и service используют одну базу данных. `HASHIDS_SALT` должен совпадать с admin, иначе зашифрованные admin ID не будут расшифровываться в service.

## Развёртывание Docker

### Админ-панель

```bash
cd admin
cp .env.docker .env
# Отредактировать .env: заменить ключи для прода

docker compose up -d
# Включает: Nginx + PHP + MySQL + Redis + Elasticsearch
```

### Портал жильцов

```bash
cd service
cp .env.docker .env
# Отредактировать .env: заменить ключи для прода

docker compose up -d
```

### План портов сервисов

| Сервис | admin | service | Описание |
|------|-------|---------|------|
| Приложение | 8787 | 8788 | HTTP webman |
| MySQL | 3306 | 3307 | проброс порта контейнера |
| Redis | 6379 | 6380 | проброс порта контейнера |
| Elasticsearch | 9200 | 9201 | проброс порта контейнера |
| Nginx | 80/443 | 80/443 | разворачивать со смещением |

> При развёртывании двух docker-compose на одном хосте порты service уже предустановлены со смещением во избежание конфликтов.

## Частые вопросы

### Q: При запуске ошибка `Call to undefined function pcntl_fork()`

В PHP отсутствует расширение pcntl.

```bash
# Ubuntu/Debian
apt install php-pcntl

# Docker
docker-php-ext-install pcntl
```

### Q: После входа сообщение о недействительном Token

Проверить совпадение следующих параметров в `.env` admin и service:
- `JWT_SECRET_KEY`
- `JWT_ALGORITHM`

### Q: Зашифрованные ID не совпадают на обеих сторонах

Убедиться, что значение `HASHIDS_SALT` в admin и service полностью одинаково.

### Q: Контейнеры Docker не сообщаются между собой по сети

Использовать имена контейнеров вместо IP (например, `DB_HOST=mysql`).

### Q: Как сбросить базу данных

```bash
mysql -u root -p -e "DROP DATABASE IF EXISTS management;"
mysql -u root -p -e "CREATE DATABASE management DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p management < docs/install.sql
```

### Q: Как настроить HTTPS

В проде рекомендуется использовать обратный прокси Nginx с терминацией TLS. Пример конфигурации — в `admin/docs/nginx-security.conf`.
