## Обзор

Система управления недвижимостью делится на **админ-панель** (внутреннее использование управляющей компанией) и **портал жильцов** (использование владельцами/арендаторами), охватывает 15 бизнес-модулей, поставляется в 3 партиях.

---

## Партия 1: Основные бизнес-процессы

### 1. Управление жилым комплексом (Community)

**Админ-панель:**
- Список комплексов (поиск, пагинация, фильтр по статусу)
- Создание/просмотр/редактирование/удаление комплекса
- Информация о комплексе: название, адрес (регион/город/район), площадь застройки, число корпусов, число квартир, застройщик, управляющая компания, контактный телефон
- Удаление требует повторного подтверждения паролем, используется мягкое удаление

**Портал жильцов:** права управления не требуются, на главной отображается информация привязанного комплекса.

### 2. Управление корпусами (Building)

**Админ-панель:**
- Список корпусов с фильтром по комплексу
- Создание/просмотр/редактирование/удаление корпуса
- Информация о корпусе: название, тип (башня/плита/вилла/коммерческий), число этажей, число квартир, число лифтов, год постройки, тип конструкции
- Поддержка сортировки

### 3. Управление квартирами (Unit)

**Админ-панель:**
- Список квартир с фильтром по корпусу
- Создание/просмотр/редактирование/удаление квартиры
- Информация о квартире: название, число квартир на этаже

### 4. Управление планировками (RoomType)

**Админ-панель:**
- CRUD списка планировок
- Информация о планировке: название (трёхкомнатная двухзальная), число комнат/залов/санузлов, план квартиры

### 5. Управление объектами недвижимости (Room)

**Админ-панель:**
- Дерево помещений (комплекс→корпус→квартира→помещение)
- Создание/просмотр/редактирование/удаление помещения
- Информация о помещении: номер, этаж, планировка, площадь (внутренняя/общая/итоговая), ориентация, отделка, назначение (жилое/коммерческое/офисное), статус (свободно/продано/сдано/собственное проживание)
- Пакетная привязка/отвязка владельцев

**Портал жильцов:**
- Список привязанных объектов недвижимости
- Детали объекта (площадь, ориентация, планировка, сведения о правах)

### 6. Управление владельцами (Owner)

**Админ-панель:**
- Список владельцев (поиск, пагинация, фильтр по статусу)
- Создание/просмотр/редактирование/удаление владельца
- Информация о владельце: ФИО, телефон (шифруется), e-mail (шифруется), удостоверение личности (шифруется), пол, дата рождения, контакт для экстренных случаев, дата заселения
- Пакетный импорт (Excel), пакетная блокировка/разблокировка, пакетное удаление
- Привязка/отвязка объектов недвижимости

**Портал жильцов:**
- Регистрация (телефон + пароль + капча, возможна проверка по привязке объекта)
- Вход (телефон + пароль + кликовая капча, защита от блокировки аккаунта)
- Просмотр/изменение личной информации
- Смена пароля, выход

### 7. Управление арендаторами (Tenant)

**Админ-панель:**
- Список арендаторов с фильтром по объекту/арендодателю
- Создание/просмотр/редактирование/удаление арендатора
- Информация об арендаторе: ФИО, телефон (шифруется), удостоверение (шифруется), срок аренды, месячная арендная плата, статус

### 8. Управление платежами (Fee)

**Типы платежей (админ-панель):**
- CRUD типов платежей: плата за обслуживание, вода, электричество, газ, отопление, парковка, ремонтный фонд, прочее
- Тариф, единица расчёта (юань/м²/мес, юань/тонна, юань/кВт·ч и т.д.), расчётный период (ежемесячно/ежеквартально/ежегодно), обязательность

**Управление счетами (админ-панель):**
- Запрос счетов по комплексу/корпусу/объекту
- Ручное создание/редактирование счёта
- Пакетная генерация счетов (выбор комплекса + типа платежа + периода, автоматически для всех помещений)
- Информация о счёте: тип платежа, сумма, пеня, расчётный период, срок оплаты
- Статусы: не оплачен/частично оплачен/оплачен/просрочен/освобождён
- Пакетные уведомления о взыскании

**Счета (портал жильцов):**
- Список моих счетов (фильтр по статусу: не оплачен/оплачен/просрочен)
- Детали счёта
- Онлайн-оплата (WeChat/Alipay, требуется повторное подтверждение паролем)
- История платежей
- Статистика платежей (годовые/месячные тренды, доли по категориям)

**Платежи (админ-панель):**
- Запрос платежей
- Регистрация офлайн-приёма (наличные/карта/банковский перевод)

### 9. Управление заявками на ремонт (Repair)

**Админ-панель:**
- Список заявок (фильтр по статусу/категории)
- Просмотр деталей заявки
- Назначение исполнителя (распределение ремонтника)
- Обновление хода ремонта

**Портал жильцов:**
- Список моих заявок
- Подача заявки (выбор объекта, категория, срочность, описание, загрузка фото, время визита)
- Просмотр деталей и хода выполнения
- Отмена заявки (только в статусе ожидания назначения, требуется подтверждение паролем)
- Оценка заявки (1-5 звёзд + текстовый отзыв)

### 10. Объявления и уведомления (Announcement)

**Админ-панель:**
- CRUD списка объявлений
- Публикация объявлений по комплексу
- Категории: уведомление/объявление/напоминание/мероприятие
- Закрепление, статусы черновик/опубликовано

**Портал жильцов:**
- Список опубликованных объявлений (фильтр по категории)
- Детали объявления

## Партия 2: Вспомогательные бизнес-процессы

### 11. Управление парковкой (Parking)

**Админ-панель:**
- Управление парковочными местами (номер, надземное/подземное, площадь, статус: свободно/продано/сдано/на ремонте)
- Управление автомобилями (номерной знак шифруется, марка, цвет, тип, привязка места/владельца)
- Запрос записей парковки (время въезда/выезда, длительность стоянки, плата)

**Портал жильцов:**
- Список моих автомобилей
- Список моих парковочных мест
- Запрос записей парковки

### 12. Управление оборудованием (Equipment)

**Админ-панель:**
- Реестр оборудования (название, номер, категория: лифт/пожарная система/домофон/видеонаблюдение/водоснабжение/электроснабжение/вентиляция)
- Информация об оборудовании: марка, модель, место установки, дата установки, окончание гарантии, расчётный срок службы
- Записи обслуживания: ежедневный осмотр/плановое ТО/ремонт неисправностей/капремонт/замена
- Персонал, стоимость, подрядчик, следующая дата ТО

### 13. Жалобы и предложения (Complaint)

**Админ-панель:**
- Список жалоб (фильтр по типу/статусу)
- Обработка жалобы (назначение обработчика, заполнение комментария)
- Регистрация повторного визита (комментарий, фиксация удовлетворённости)

**Портал жильцов:**
- Список моих жалоб/предложений
- Подача жалобы/предложения (тип: жалоба/предложение/благодарность, категория: сервис/окружение/безопасность/инфраструктура/шум/самострой)
- Анонимная подача, загрузка изображений
- Просмотр хода обработки
- Оценка удовлетворённости

### 14. Управление посетителями (Visitor)

**Админ-панель:**
- Согласование заявок на визит
- Запрос записей визитов

**Портал жильцов:**
- Заявка на визит (ФИО посетителя, телефон, удостоверение, номер автомобиля, число сопровождающих, причина визита, планируемое время)
- Генерация кода пропуска
- Изменение/отмена заявки

### 15. Управление договорами (Contract)

**Админ-панель:**
- Список договоров (фильтр по типу/статусу)
- Типы договоров: договор управления/аренды/обслуживания/оказания услуг/закупки
- Информация о договоре: номер, стороны, сумма, срок действия, дата подписания, вложения
- Статусы: черновик/в исполнении/истёк/расторгнут/продлён

### 16. Управление финансами (Finance)

**Админ-панель:**
- Управление доходами (плата за обслуживание/парковка/аренда/реклама/ремонтный фонд/прочее)
- Управление расходами (персонал/закупка оборудования/обслуживание/энергопотребление/уборка и озеленение/офис/налоги/прочее)
- Отчёты по доходам и расходам (месячные/квартальные/годовые)

## Партия 3: Расширенные функции

### 17. Охрана и патрулирование (Security Patrol)

**Админ-панель:**
- Управление маршрутами патрулирования (координаты маршрута, контрольные точки)
- Записи патрулирования (время начала/окончания, длительность, комментарии об отклонениях)
- Статистика процента завершения патрулей

### 18. Управление уборкой (Cleaning)

**Админ-панель:**
- Управление зонами уборки (расположение, площадь, периодичность: ежедневно/еженедельно/раз в две недели/ежемесячно)
- Записи уборки (время, проверяющий, комментарии проверки, фото с места)
- Статистика процента завершения уборок

### 19. Управление озеленением (Green)

**Админ-панель:**
- Управление зонами озеленения (расположение, площадь, основные растения)
- Записи ухода (полив/стрижка/удобрение/обработка от вредителей/досадка, стоимость)

### 20. Мероприятия сообщества (Activity)

**Админ-панель:**
- Управление мероприятиями (название, описание, категория: спорт/праздник/благотворительность/лекция/семейное)
- Обложка, место, максимум участников, время, стоимость
- Статусы: идёт запись/в процессе/завершено/отменено
- Просмотр списка записавшихся

**Портал жильцов:**
- Список мероприятий (фильтр: идёт запись/в процессе)
- Детали мероприятия
- Запись/отмена записи

### 21. Управление энергопотреблением (Energy)

**Админ-панель:**
- Управление приборами учёта (электросчётчик/водомер/газовый счётчик/теплосчётчик, номер)
- Записи показаний (текущее показание, расход, тариф, сумма)
- Автоматическая генерация связанных счетов

### 22. Управление персоналом (Staff)

**Админ-панель:**
- Информация о сотрудниках (ФИО, телефон шифруется, удостоверение шифруется, должность, отдел, дата приёма)
- Отделы: управление/поддержка/инженерный/охрана/уборка/озеленение/финансы
- Статусы: на работе/уволен/в отпуске

## Панели визуализации и экспорт

### Панель приборов

**Панель администратора:**
- Карточки ключевых показателей: общая сумма к оплате, фактически получено, доля задолженности, заселённость
- Линейный график тренда платежей (месячный/квартальный)
- Круговая диаграмма по категориям платежей
- Статистика заявок на ремонт (по категории, по статусу)
- Статистика жалоб
- Последние журналы операций

**Главная портала жильцов:**
- Число моих объектов, сумма к оплате, число обрабатываемых заявок, последние объявления

### Экспорт Excel

- Экспорт списка владельцев
- Экспорт отчёта по счетам
- Экспорт записей платежей
- Экспорт финансового отчёта
- При экспорте чувствительные данные автоматически маскируются

### Экспорт PDF

- Экспорт визуализации панели приборов
- Финансовый отчёт PDF (заголовок с копирайтом + неудаляемый водяной знак копирайта в нижнем колонтитуле)
- Альбомная ориентация A4

## Сквозные возможности модулей

| Возможность | Описание |
|------|------|
| Защита ID | все ID в интерфейсах передаются в кодировке hashids |
| Шифрование данных | чувствительные поля (телефон/e-mail/удостоверение): AES-256-CBC на уровне API, encryptable на уровне БД |
| Аудит операций | все операции POST/PUT/DELETE администратора записываются автоматически, включая автоопределение источника |
| Управление правами | RBAC с точностью method.path, у супер-администратора идентификатор * |
| Защита от ограничения частоты | Redis скользящее окно, вход 10 раз/мин, регистрация 5 раз/мин |
| Капча | кликовая китайская капча, обязательна при входе/регистрации |
| Мягкое удаление | владельцы, комплексы, объекты недвижимости, объявления поддерживают мягкое удаление |
| Интернационализация | двуязычность китайский/английский, PHP symfony/translation + Flutter GetX Translations, по умолчанию китайский, откат на английский |
| Документация API | автоматическая генерация `hg/apidoc`: 57 из 58 контроллеров аннотированы по 10 группам (Base/Docs/Install без группы), `/apidoc/config` предоставляет API конфигурации |
| Тестирование | процесс TDD, 133 теста/465 утверждений, service 100% прохождение, flutter analyze без замечаний |
| Flutter Web | 13 страниц (вход/главная/платежи/заявки на ремонт/личный кабинет и др.), стиль настольного ПК, управление состоянием GetX |
| HarmonyOS | полный каркас проекта, сервисный слой ArkTS + аутентификация + вход/главная, @ohos.net.http |

## Расширенные функции (партия 4)

### Центр сообщений
- Настраиваемые шаблоны уведомлений (push в приложение/СМС/e-mail)
- Автоматические уведомления о счетах, ходе ремонта, публикации объявлений
- Список сообщений портала жильцов + управление прочитанными

### Движок рабочих процессов согласования
- Настраиваемые типы и шаги согласования (руководитель→менеджер→директор)
- Назначение заявок/согласование посетителей/согласование договоров по стандартному процессу
- История согласований отслеживаема

### Интеграция платежей
- Управление заказами оплаты WeChat/Alipay
- Обработка колбэков платежей, возвраты, сверка
- Автоматическое обновление связанных счетов

### Голосования владельцев
- Обычные голосования + собрания владельцев (взвешивание по площади)
- Управление вариантами, записи голосов, автоматический подсчёт
- Статистика участия

### Автоматическая эскалация SLA по заявкам на ремонт
- Настройка сроков ответа/устранения по категории + срочности
- Автоматическая эскалация вышестоящей роли при превышении срока
- Автоматическая фиксация штрафов за превышение срока

### Интеллектуальное взыскание
- Настройка ступенчатой стратегии взыскания (дней просрочки → действие)
- Автоматическое сопоставление просроченных счетов и взыскание (App/СМС/телефон/визит)
- Автоматический расчёт пени

### Мобильное патрулирование
- Выдача задач патрулирования (GPS-маршрут + контрольные точки)
- Отметка на мобильном устройстве (геолокация + фото + отметка отклонений)
- Статистика процента завершения патрулей

### Комьюнити-магазин
- Управление категориями товаров/публикацией/снятием с продажи
- Просмотр владельцами + заказ + отслеживание заказа
- Управление доставкой/возвратами

### Распознавание лиц
- Регистрация лиц владельцев (интеграция со сторонним сервисом распознавания)
- Проверка и подтверждение админ-панелью
- Связь с пропуском через дверь

### Управление группой комплексов
- Связь «группа→комплекс» многие-ко-многим
- Сводные данные по нескольким комплексам (единое представление объектов/владельцев/платежей)

### Интеллектуальные ответы на вопросы
- Управление базой знаний (категории/статьи/ключевые слова)
- Автоматическое сопоставление вопросов владельцев
- История диалогов + статистика доли решённых

### Большой экран данных
- Полноэкранная визуализация данных недвижимости в реальном времени
- Четыре панели: платежи/заявки на ремонт/оборудование/энергопотребление
- Автоматическое циклическое обновление
