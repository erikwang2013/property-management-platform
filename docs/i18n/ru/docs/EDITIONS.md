## Сравнение функциональных модулей

### Базовая (Lite)

Ядро управления недвижимостью: общая система админ-панели + 10 основных бизнес-модулей.

**Админ-панель**: дашборд, CRUD пользователей/ролей/прав/настроек/журналов, CRUD комплексов/корпусов/квартир/планировок/объектов/жильцов/арендаторов/платежей/заявок на ремонт/объявлений

**Портал жильцов**: регистрация/вход, главная, моя недвижимость, оплата счетов, подача заявок на ремонт/оценка, просмотр объявлений, личная информация

---

### Стандартная (Standard)

К базовой добавляются 6 вспомогательных бизнес-модулей + визуализация панели + экспорт данных.

**Новое в админ-панели**: парковочные места/автомобили CRUD, учёт оборудования + ТО, обработка жалоб + обратная связь, согласование гостей, управление договорами, управление доходами/расходами + статистика

**Новое в портале жильцов**: мои автомобили/парковочные места, записи парковки, заявки на гостей/код доступа

---

### Полная (Full)

К стандартной добавляются продвинутые модули + 12 расширений.

**Новое в админ-панели**: маршруты патрулирования + записи, зоны уборки + записи, зоны озеленения + уход, управление мероприятиями сообщества, учёт энергопотребления + показания счётчиков, управление сотрудниками, шаблоны уведомлений + отправка, движок согласований, платёжные заказы + возвраты, управление голосованиями + правила SLA + стратегии напоминаний о долге + задачи обхода + управление магазином + проверка лиц + управление группой компаний + база знаний

**Новое в портале жильцов**: запись на мероприятия, бронирование парковки/гостей, уведомления, голосование + подсчёт голосов, просмотр товаров + заказы, умные ответы на вопросы, регистрация лица

## Система безопасности (общая для трёх версий)

18 уровней эшелонированной защиты: код подтверждения → подтверждение пароля → случайная проверка → сканирование безопасности → блокировка атак → HTTPS + AES-256-CBC → JWT → контроль сессий → блокировка аккаунта → RBAC → ограничение частоты → защита ID → шифрование запросов → шифрование хранилища → маскирование при отображении → аудит → CSP → водяной знак авторских прав

## Путь миграции

```
Базовая (Lite)
  │
  │  + 6 вспомогательных модулей + панель + экспорт
  ▼
Стандартная (Standard)
  │
  │  + 6 продвинутых модулей + 12 расширений
  ▼
Полная (Full)
```

Для обновления достаточно выполнить SQL-миграции соответствующего этапа — без миграции данных и разрушительных изменений.

## Демонстрационный процесс

**Подготовка**: выполнен `docs/install.sql` (полная структура таблиц, включая все версии); в `admin/.env` настроено подключение к БД. Различия версий — в регистрации маршрутов и видимости функций; структура таблиц едина и полна.

### Базовая (Lite)

1. Загрузить демо-данные: `cd admin && php ../scripts/demo_data.php` (идемпотентно, можно повторять)
2. Объём демо-данных: комплексы/корпуса/квартиры/планировки/объекты/жильцы/арендаторы/платежи/счета/объявления + демо-аккаунт — покрывает базовые модули Lite
3. Что смотреть: дашборд админ-панели + CRUD пользователей/ролей/прав/настроек/журналов + CRUD объектов/жильцов/арендаторов/платежей/заявок на ремонт/объявлений; в портале жильцов — регистрация/вход, главная, моя недвижимость, оплата счетов, заявки на ремонт, объявления
4. Различия маршрутов: регистрируется только группа Lite, блоки, обёрнутые в `edition_supports('standard'/'full')`, не регистрируются (`admin/config/route.php`)

### Стандартная (Standard)

1. Загрузить демо-данные: `cd admin && php ../scripts/demo_data.php` (идемпотентно, повторное выполнение лишь дополняет недостающее)
2. Вспомогательные модули содержат мало данных — парковку/оборудование/жалобы/гостей/договоры/доходы-расходы достаточно внести в небольшом объёме вручную
3. Что смотреть: в админ-панели добавлены парковочные места/автомобили, учёт оборудования + ТО, обработка жалоб + обратная связь, согласование гостей, управление договорами, управление доходами/расходами + статистика; в портале жильцов — мои автомобили/парковочные места, записи парковки, заявки на гостей/код доступа
4. Различия маршрутов: добавляется группа `edition_supports('standard')`, группа Lite сохраняется

### Полная (Full)

1. Загрузить демо-данные: `cd admin && php ../scripts/demo_data.php` (идемпотентно)
2. Продвинутые модули (платежи/согласования/голосования/магазин/обход/лица/группа/база знаний) — демо-данные вносятся по мере необходимости, либо создаются демо-аккаунтом напрямую
3. Что смотреть: поверх Standard — патрулирование/уборка/озеленение/энергопотребление/сотрудники/шаблоны уведомлений/движок согласований/платёжные заказы/голосования/SLA/напоминания/обход/магазин/лица/группа/база знаний; в портале жильцов — запись на мероприятия, уведомления, голосование, заказы в магазине, умные ответы, регистрация лица
4. Различия маршрутов: полная регистрация, действует группа `edition_supports('full')` (`admin/config/route.php`)

### Переключение версии

```bash
# В admin/.env задать целевую версию (последовательно, full включает все функции)
EDITIONS=lite|standard|full

# Перезапуск webman для применения (контейнер: docker compose restart app; голый сервер: php start.php restart)
```

- Конфигурация fail-fast: при недопустимом значении `EDITIONS` сразу выбрасывается ошибка (`admin/config/edition.php`), без тихого отката к неверной версии.
- Скрипт демо-данных идемпотентен, при смене версии очистка БД не нужна; данных модулей Standard/Full мало — их вносит реальный бизнес.
