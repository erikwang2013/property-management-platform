# Список пробелов мобильной версии

> Дата создания: 2026-08-16 · Источник: pmp-team ci-agent (P3-③ инвентаризация текущего состояния, только чтение)
> Соответствует дорожной карте: docs/PROJECT_PLAN.md P3 — «Расширить 7 страниц HarmonyOS до ключевых путей (оплата/ремонт/объявления/гости/парковка), мобильная адаптация Flutter-портала жильцов»

## 1. Текущее состояние HarmonyOS-портала жильцов (apps/harmonyos, 7 страниц)

| Страница | Маршрут (зарегистрирован в main_pages.json) | Вызываемый API |
|------|------------------------------|---------|
| LoginPage | pages/LoginPage | вход (AuthService) |
| HomePage | pages/HomePage | GET /service/home (дашборд: к оплате/заявки/число объектов + список объявлений) |
| FeeBillsPage | pages/FeeBillsPage | GET /service/fees/bills?page=1&per_page=50 |
| RepairListPage | pages/RepairListPage | GET /service/repairs |
| RepairSubmitPage | pages/RepairSubmitPage | POST /service/repair |
| AnnouncementPage | pages/AnnouncementPage | GET /service/announcements?page=1&per_page=50 |
| ProfilePage | pages/ProfilePage | GET /service/profile、POST /service/profile/logout |

**Текущая навигация** (во всём приложении всего 4 перехода): Login→Home、Home→Login (выход)、Profile→Login、RepairList→RepairSubmit. На HomePage только карточки статистики + список объявлений, сетки входов в функции нет; страницы FeeBills/Announcement/Profile существуют, но **входов на них нет — они недостижимы**.

## 2. Сопоставление ключевых путей HarmonyOS

| Ключевой путь | Текущее состояние | Тип пробела |
|---------|------|---------|
| Оплата | страница есть, API работает | чисто фронтенд: на Home нет входа (недостижимо) |
| Ремонт | страницы списка+подачи есть, API работает | чисто фронтенд: на Home нет входа (недостижимо) |
| Объявления | страница есть, API работает | чисто фронтенд: на Home нет входа (недостижимо) |
| Гости | страница отсутствует | нужна новая страница (API уже есть: GET/POST/PUT/DELETE /visitor*) |
| Парковка | страница отсутствует | нужна новая страница (API уже есть: /parking/vehicles、/parking/spaces、/parking/records) |

Пробелов в бэкенде нет: API service для всех 5 ключевых путей готовы (fees/repairs/announcements — постоянные маршруты; parking/visitors — внутри гейта стандартной версии). В ApiService.ets уже есть универсальные get/post/put/delete, новые страницы могут их переиспользовать.

## 3. Текущее состояние Flutter-портала жильцов (apps/flutter, 13 модулей)

**Список страниц**: login、home、fee、repair、parking×3、visitor×2、activity、notification、vote、mall×3、chat、face、profile — все зарегистрированы в маршрутах (getPages в app.dart), все 5 ключевых путей реализованы.

**Проблемы мобильной адаптации**: только home_page / login_page используют адаптивные брейкпоинты LayoutBuilder/MediaQuery; **в 10 страницах жёстко закодирована ширина для десктопа**, на мобильной ширине (<400px) гарантированно переполнение RenderFlex:

| Страница | Жёсткая кодировка |
|------|--------|
| chat_page | SizedBox(width: 600) |
| mall_products_page | width: 800 |
| mall_product_detail / mall_orders | SizedBox(width: 600) |
| notification_list | width: 480 + SizedBox(width: 600) |
| vote_list / vote_detail | SizedBox(width: 600) |
| activity_detail、parking_records/vehicles、visitor_list、face_register | без обработки брейкпоинтов (ожидаются аналогичные проблемы, построчно не проверялось) |

Кроме того: нет нижней навигационной панели (BottomNavigationBar), входы через AppBar + сетку; отступы страниц 24 — в десктопном стиле. Двуязычность i18n уже есть.
