## Сквозные возможности

### Шифрованная передача ID
Во всех API-запросах и ответах поля ID кодируются/декодируются через `erikwang2013/hashids`. Клиент получает строку hashid (например, `aB3xK9mW2pQ7rT5v`), бэкенд декодирует её в BIGINT для операций.

### Защита чувствительных данных
- Уровень API-передачи: `erikwang2013/encryption` — AES-256-CBC
- Уровень хранения в БД: `erikwang2013/encryptable` — автоматическое шифрование/дешифрование через casts Eloquent Model
- Уровень отображения: телефон 138\*\*\*\*1234, email a\*\*\*@e.com

### Аудит операций
Все операции POST/PUT/DELETE админ-панели записываются автоматически: пользователь операции, IP, путь, параметры (замаскированы), время операции, источник (web/ios/android/harmonyos/windows/macos/linux/ipados).

### Контроль прав
- Админ-панель: авторизация RBAC с точностью method.path, суперадмин `*` пропускает проверку
- Портал жильцов: аутентификация JWT Bearer Token, жилец работает только со своими данными

### Защита от угроз
18 уровней эшелонированной защиты: код подтверждения → подтверждение пароля → случайная проверка → сканирование безопасности → блокировка атак → шифрование передачи → JWT → контроль сессий → блокировка аккаунта → RBAC → ограничение частоты → защита ID → шифрование запросов → шифрование хранилища → маскирование при отображении → аудит → CSP → водяной знак авторских прав

### Экспорт
- Excel: PhpSpreadsheet, заголовок синий на белом + закреплённая первая строка + автофильтр + маскирование чувствительных данных
- PDF: Dompdf A4 альбомная, авторские права в шапке + неудаляемый водяной знак в подвале
- Экспорт данных визуальной панели в PDF

### Поисковый движок
- `erikwang2013/webman-scout` поверх Elasticsearch
- Автосинхронизация индекса (автопушка при добавлении/изменении/удалении)
- Префикс индекса `management_`, совпадает с префиксом таблиц БД

### Интернационализация (i18n)
- **PHP бэкенд**: symfony/translation — `resource/translations/{zh_CN,en}/messages.php`, 42 ключа перевода, контроллеры получают перевод через `__()`
- **Flutter Web**: GetX `Translations` — `lib/i18n/messages.dart`, 101 ключ перевода, страницы используют расширение `.tr`
- **HarmonyOS**: ресурсные квалификаторы `resources/{base,en_US}/element/string.json`
- **Язык по умолчанию**: упрощённый китайский (zh_CN), резервный — английский (en)
- **Заголовок запроса**: поддержка `Accept-Language` для управления языком ответа
