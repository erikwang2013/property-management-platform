## مقارنة الوحدات الوظيفية

### الأساسي (Lite)

إدارة العقارات الأساسية، تشمل النظام العام للوحة الإدارة + 10 وحدات أعمال أساسية.

**لوحة الإدارة**: لوحة القيادة، CRUD للمستخدم/الدور/الصلاحيات/الإعدادات/السجلات، CRUD للمجمع/المبنى/الوحدة/نوع الوحدة/العقار/المالك/المستأجر/الرسوم/طلب الإصلاح/الإعلان

**بوابة الملاك**: التسجيل/تسجيل الدخول، الصفحة الرئيسية، عقاراتي، دفع الفواتير، تقديم طلب الإصلاح/التقييم، عرض الإعلانات، المعلومات الشخصية

---

### القياسي (Standard)

يضيف فوق الأساسي 6 وحدات أعمال مساعدة + تصور اللوحات + تصدير البيانات.

**إضافة لوحة الإدارة**: CRUD لمواقف/مركبات، سجل المعدات + الصيانة، معالجة الشكاوى + المتابعة، موافقات الزوار، إدارة العقود، إدارة الإيرادات والمصروفات + الإحصائيات

**إضافة بوابة الملاك**: مركباتي/مواقفي، سجل المواقف، حجز الزوار/رمز المرور

---

### الكامل (Full)

يضيف فوق القياسي وحدات متقدمة + 12 وظيفة موسعة.

**إضافة لوحة الإدارة**: مسارات الدوريات + السجلات، مناطق النظافة + السجلات، المناطق الخضراء + الصيانة، إدارة أنشطة المجتمع، عدادات الطاقة + قراءتها، إدارة الموظفين، قوالب الإشعارات + الإرسال، محرك الموافقات، طلبات الدفع + الاسترداد، إدارة التصويت + قواعد SLA + استراتيجيات التحصيل + مهام التفتيش + إدارة المتجر + مراجعة الوجوه + إدارة المجموعة + قاعدة المعرفة

**إضافة بوابة الملاك**: التسجيل في أنشطة المجتمع، حجز المواقف/الزوار، إشعارات الرسائل، التصويت + فرز الأصوات، تصفح المنتجات + الطلب، الأسئلة والأجوبة الذكية، تسجيل الوجه

الترقية لا تتطلب سوى تنفيذ ملفات SQL للترحيل الخاصة بالدفعة المقابلة، دون الحاجة إلى ترحيل بيانات أو تغييرات مدمرة.

## مسار العرض التوضيحي

**التحضير**: تم تنفيذ `docs/install.sql` (هيكل الجداول الكامل، يشمل جداول جميع الإصدارات)؛ وتم إعداد اتصال قاعدة البيانات في `admin/.env`. الفروق بين الإصدارات في تسجيل المسارات وظهور الوظائف، أما هيكل الجداول فموحد وكامل.

### الأساسي (Lite)

1. تنفيذ بيانات العرض: `cd admin && php ../scripts/demo_data.php` (تجمّعي، يمكن تنفيذه مراراً)
2. نطاق بيانات العرض: مجمع/مبنى/وحدة/نوع وحدة/عقار/مالك/مستأجر/رسوم/فاتورة/إعلان + حساب عرض، يغطي وحدات Lite الأساسية
3. ماذا تشاهد: لوحة قيادة لوحة الإدارة + المستخدم/الدور/الصلاحيات/الإعدادات/السجلات + CRUD للعقار/المالك/المستأجر/الرسوم/طلب الإصلاح/الإعلان؛ في بوابة الملاك: التسجيل/تسجيل الدخول، الصفحة الرئيسية، عقاراتي، دفع الفواتير، طلب الإصلاح، الإعلانات
4. اختلاف المسارات: يتم تسجيل مجموعة Lite فقط، ولا تُسجَّل الكتل المحاطة بـ `edition_supports('standard'/'full')` (`admin/config/route.php`)

### القياسي (Standard)

1. تنفيذ بيانات العرض: `cd admin && php ../scripts/demo_data.php` (تجمّعي، التنفيذ المتكرر يكمّل الناقص فقط دون تكرار البيانات)
2. بيانات الوحدات المساعدة قليلة، يكفي إدخال القليل يدوياً للمواقف/المعدات/الشكاوى/الزوار/العقود/الإيرادات والمصروفات
3. ماذا تشاهد: إضافة في لوحة الإدارة لمواقف/مركبات، سجل المعدات + الصيانة، معالجة الشكاوى + المتابعة، موافقات الزوار، إدارة العقود، إدارة الإيرادات والمصروفات + الإحصائيات؛ إضافة في بوابة الملاك لمركباتي/مواقفي، سجل المواقف، حجز الزوار/رمز المرور
4. اختلاف المسارات: إضافة مجموعة `edition_supports('standard')` مع الإبقاء على مجموعة Lite

### الكامل (Full)

1. تنفيذ بيانات العرض: `cd admin && php ../scripts/demo_data.php` (تجمّعي)
2. بيانات الوحدات المتقدمة (الدفع/الموافقات/التصويت/المتجر/التفتيش/الوجه/المجموعة/قاعدة المعرفة) تُدخل حسب الحاجة، أو تُنشأ مباشرة بحساب العرض
3. ماذا تشاهد: فوق القياسي تُضاف الدوريات/النظافة/المساحات الخضراء/الطاقة/الموظفون/قوالب الإشعارات/محرك الموافقات/طلبات الدفع/التصويت/SLA/التحصيل/التفتيش/المتجر/الوجه/المجموعة/قاعدة المعرفة؛ في بوابة الملاك: تسجيل الأنشطة، إشعارات الرسائل، التصويت، طلبات المتجر، الأسئلة والأجوبة الذكية، تسجيل الوجه
4. اختلاف المسارات: تسجيل كامل، تتفعيل مجموعة `edition_supports('full')` (`admin/config/route.php`)

### تبديل الإصدار

```bash
# تعيين الإصدار الهدف في admin/.env (تراكم تدريجي، full يشمل جميع الوظائف)
EDITIONS=lite|standard|full

# إعادة تشغيل webman لتفعيل التغيير (نشر حاويات: docker compose restart app؛ جهاز فعلي: php start.php restart)
```

- إعداد fail-fast: أي قيمة غير صالحة لـ `EDITIONS` تسبب خطأً فورياً (`admin/config/edition.php`)، دون العودة الصامتة لإصدار خاطئ.
- سكربت بيانات العرض تجمّعي، وتبديل الإصدارات لا يتطلب مسح قاعدة البيانات؛ بيانات وحدات Standard/Full قليلة، تُدخل من خلال الأعمال الحقيقية.
