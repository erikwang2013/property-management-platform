## ميزات عبر الوظائف

### تشفير نقل المعرّفات
تُرمَّز حقول ID في جميع طلبات واستجابات واجهات API باستخدام `erikwang2013/hashids`. يستلم العميل سلسلة hashid (مثل `aB3xK9mW2pQ7rT5v`)، ويفكها الخادم إلى BIGINT للعملية.

### حماية البيانات الحساسة
- طبقة نقل API: `erikwang2013/encryption` — AES-256-CBC
- طبقة تخزين قاعدة البيانات: `erikwang2013/encryptable` — تشفير/فك تلقائي عبر Eloquent Model casts
- طبقة عرض الواجهة: رقم الهاتف 138****1234، البريد a***@e.com

### تدقيق العمليات
تُسجَّل جميع عمليات POST/PUT/DELETE في لوحة الإدارة تلقائياً، وتشمل المستخدم المنفذ والعنوان والمسار والمعلمات (المخفاة) ووقت العملية ومنصة المصدر (web/ios/android/harmonyos/windows/macos/linux/ipados).

### التحكم بالصلاحيات
- لوحة الإدارة: تفويض RBAC بدقة method.path، والمدير الفائق `*` يتجاوز الفحص
- بوابة الملاك: مصادقة JWT Bearer Token، ويمكن للمالك التعامل مع بياناته فقط

### الحماية الأمنية
دفاع متعمق من 18 طبقة: رمز التحقق ← تأكيد كلمة المرور ← التحقق العشوائي ← الفحص الأمني ← اعتراض الهجمات ← تشفير النقل ← JWT ← التحكم بالجلسات ← قفل الحساب ← RBAC ← تحديد المعدل ← حماية المعرّف ← تشفير الطلب ← تشفير التخزين ← إخفاء العرض ← التدقيق ← CSP ← العلامة المائية

### وظائف التصدير
- Excel: PhpSpreadsheet، ترويسة زرقاء بنص أبيض + تثبيت الصف الأول + تصفية تلقائية + إخفاء البيانات الحساسة
- PDF: Dompdf A4 أفقي، حقوق نشر في رأس الصفحة + علامة مائية غير قابلة للإزالة في التذييل
- تصدير بيانات تصور اللوحات إلى PDF

### محرك البحث
- مشغل Elasticsearch عبر `erikwang2013/webman-scout`
- مزامنة فهرس تلقائية (دفع تلقائي عند الإضافة/الحذف/التعديل)
- بادئة الفهرس `erik_`، مطابقة لبادئة جداول قاعدة البيانات

### التدويل (i18n)
- **خادم PHP**: symfony/translation — `resource/translations/{zh_CN,en}/messages.php`، 42 مفتاح ترجمة، تصل المتحكمات إلى الترجمات عبر `__()`
- **Flutter Web**: GetX `Translations` — `lib/i18n/messages.dart`، 101 مفتاح ترجمة، تستخدمه الصفحات عبر امتداد `.tr`
- **HarmonyOS**: مؤهلات الموارد `resources/{base,en_US}/element/string.json`
- **اللغة الافتراضية**: الصينية المبسطة (zh_CN)، لغة الانحدار الإنجليزية (en)
- **ترويسة الطلب**: دعم `Accept-Language` للتحكم بلغة الاستجابة

### تغطية الاختبارات
- **إطار الاختبار**: PHPUnit 12.x
- **مسار TDD**: أحمر←أخضر←إعادة هيكلة، الاختبار قبل الكود
- **لوحة الإدارة**: 60 اختباراً، 164 تأكيداً، تغطي الخدمات الأساسية وإعدادات البيئة والتحقق الأمني
- **الأعمال**: 18 اختباراً، 45 تأكيداً، نسبة نجاح 100%
- **الإجمالي**: 78 اختباراً، 209 تأكيدات
- **نطاق التغطية**: تفرد توليد Snowflake ID، رحلة ترميز/فك Hashids، تنسيق الاستجابة الموحد، التحقق من مخطط 64 جدولاً، تطابق مفاتيح الترجمة الصينية/الإنجليزية
- **Flutter**: flutter analyze بدون أي مشاكل
- **توثيق API**: توليد تلقائي عبر `hg/apidoc`، admin (10 مجموعات) + service (9 مجموعات)، منظمة حسب الوحدات الوظيفية
