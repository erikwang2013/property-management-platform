## نظرة عامة

ينقسم نظام إدارة العقارات إلى **لوحة الإدارة** (للاستخدام الداخلي لشركة العقارات) و**بوابة الملاك** (لاستخدام ملاك/مستأجري المجمعات)، تغطي 15 وحدة أعمال، تُسلَّم في 3 دفعات.

---

## الدفعة الأولى: الأعمال الأساسية

### 1. إدارة المجمعات السكنية (Community)

**لوحة الإدارة:**
- قائمة المجمعات (بحث، ترقيم صفحات، تصفية الحالة)
- إنشاء/عرض/تعديل/حذف مجمع
- معلومات المجمع: الاسم، العنوان (محافظة/مدينة/منطقة)، مساحة البناء، عدد المباني، عدد الوحدات السكنية، المطوّر، شركة العقارات، رقم الاتصال
- الحذف يتطلب تأكيدًا ثانويًا بكلمة المرور، ويستخدم حذفًا ناعمًا

**بوابة الملاك:** لا تتطلب صلاحيات إدارية، الصفحة الرئيسية تعرض معلومات المجمع المرتبط.

### 2. إدارة المباني (Building)

**لوحة الإدارة:**
- تصفية قائمة المباني حسب المجمع
- إنشاء/عرض/تعديل/حذف مبنى
- معلومات المبنى: الاسم، النوع (برج/لوحي/فيلا/تجاري)، عدد الطوابق، عدد الوحدات، عدد المصاعد، سنة البناء، نوع الإنشاء
- دعم الترتيب

### 3. إدارة الوحدات (Unit)

**لوحة الإدارة:**
- تصفية قائمة الوحدات حسب المبنى
- إنشاء/عرض/تعديل/حذف وحدة
- معلومات الوحدة: الاسم، عدد الوحدات في الطابق

### 4. إدارة أنواع الوحدات (RoomType)

**لوحة الإدارة:**
- CRUD لقائمة أنواع الوحدات
- معلومات النوع: الاسم (ثلاث غرف وصالتان)، عدد الغرف/الصالات/الحمامات، مخطط النوع

### 5. إدارة العقارات (Room)

**لوحة الإدارة:**
- عرض شجرة العقارات (مجمع←مبنى←وحدة←عقار)
- إنشاء/عرض/تعديل/حذف عقار
- معلومات العقار: رقم الوحدة، الطابق، النوع، المساحة (صافية/مشتركة/إجمالية)، الاتجاه، التشطيب، الاستخدام (سكني/تجاري/مكتبي)، الحالة (شاغر/مباع/مؤجر/سكن ذاتي)
- ربط/فك ربط الملاك بكميات كبيرة

**بوابة الملاك:**
- عرض قائمة عقاراتي المرتبطة
- عرض تفاصيل العقار (المساحة، الاتجاه، النوع، معلومات الملكية)

### 6. إدارة الملاك (Owner)

**لوحة الإدارة:**
- قائمة الملاك (بحث، ترقيم صفحات، تصفية الحالة)
- إنشاء/عرض/تعديل/حذف مالك
- معلومات المالك: الاسم، رقم الهاتف (مشفر)، البريد (مشفر)، الهوية (مشفر)، الجنس، تاريخ الميلاد، جهة الاتصال الطارئة، تاريخ الانتقال
- استيراد جماعي (Excel)، تفعيل/تعطيل جماعي، حذف جماعي
- ربط/فك ربط العقارات

**بوابة الملاك:**
- التسجيل (هاتف + كلمة مرور + رمز تحقق، يمكن ربط عقار للتحقق)
- تسجيل الدخول (هاتف + كلمة مرور + رمز تحقق بالنقر، حماية بقفل الحساب)
- عرض/تعديل المعلومات الشخصية
- تغيير كلمة المرور، تسجيل الخروج

### 7. إدارة المستأجرين (Tenant)

**لوحة الإدارة:**
- تصفية قائمة المستأجرين حسب العقار/المؤجر
- إنشاء/عرض/تعديل/حذف مستأجر
- معلومات المستأجر: الاسم، رقم الهاتف (مشفر)، الهوية (مشفر)، بداية/نهاية العقد، الإيجار الشهري، الحالة

### 8. إدارة الرسوم (Fee)

**أنواع الرسوم (لوحة الإدارة):**
- CRUD لأنواع الرسوم: رسوم العقار، المياه، الكهرباء، الغاز، التدفئة، رسوم المواقف، صندوق الصيانة، أخرى
- السعر الوحدوي، وحدة الفوترة (يوان/م²/شهر، يوان/طن، يوان/كيلوواط وغيرها)، دورة الفوترة (شهري/ربع سنوي/سنوي)، هل إلزامية

**إدارة الفواتير (لوحة الإدارة):**
- الاستعلام عن الفواتير حسب المجمع/المبنى/العقار
- إنشاء/تعديل الفواتير يدويًا
- توليد فواتير جماعية (اختيار مجمع + نوع رسوم + دورة، توليد تلقائي لكل الوحدات)
- معلومات الفاتورة: نوع الرسوم، المبلغ، غرامة التأخير، دورة الرسوم، تاريخ الاستحقاق
- الحالة: غير مدفوعة/مدفوعة جزئيًا/مدفوعة/متأخرة/معفاة
- إشعار تحصيل جماعي

**الفواتير (بوابة الملاك):**
- قائمة فواتيري (تصفية حسب الحالة: غير مدفوعة/مدفوعة/متأخرة)
- تفاصيل الفاتورة
- الدفع عبر الإنترنت (WeChat/Alipay، يتطلب تأكيدًا ثانويًا بكلمة المرور)
- الاستعلام عن سجلات الدفع
- إحصاءات الرسوم (اتجاهات شهرية/سنوية، نسبة توزيع أنواع الرسوم)

**سجلات الدفع (لوحة الإدارة):**
- الاستعلام عن سجلات الدفع
- تسجيل التحصيل خارجيًا (نقدًا/بطاقة/تحويل بنكي)

### 9. إدارة طلبات الإصلاح (Repair)

**لوحة الإدارة:**
- قائمة طلبات الإصلاح (تصفية حسب الحالة/التصنيف)
- عرض تفاصيل طلب الإصلاح
- إرسال العمالة (تخصيص فني الإصلاح)
- تحديث تقدم الإصلاح

**بوابة الملاك:**
- قائمة طلبات إصلاحي
- تقديم طلب إصلاح (اختيار عقار، تصنيف، درجة الاستعجال، الوصف، رفع الصور، موعد محدد)
- عرض تفاصيل وتقدم طلب الإصلاح
- إلغاء طلب الإصلاح (حالة الانتظار فقط، يتطلب تأكيد كلمة المرور)
- تقييم الإصلاح (1-5 نجوم + تقييم نصي)

### 10. الإعلانات والإشعارات (Announcement)

**لوحة الإدارة:**
- CRUD لقائمة الإعلانات
- نشر الإعلانات حسب المجمع
- التصنيفات: إشعار/إعلان/تنبيه/نشاط
- تثبيت، حالة مسودة/منشور

**بوابة الملاك:**
- عرض قائمة الإعلانات المنشورة (تصفية حسب التصنيف)
- تفاصيل الإعلان

## الدفعة الثانية: الأعمال المساعدة

### 11. إدارة المواقف (Parking)

**لوحة الإدارة:**
- إدارة المواقف (الرقم، أرضي/تحت أرضي، المساحة، الحالة: شاغر/مباع/مؤجر/صيانة)
- إدارة المركبات (رقم اللوحة مشفر، العلامة التجارية، اللون، النوع، ربط الموقف/المالك)
- الاستعلام عن سجلات المواقف (وقت الدخول/الخروج، مدة البقاء، الرسوم)

**بوابة الملاك:**
- قائمة مركباتي
- قائمة مواقفي
- الاستعلام عن سجلات المواقف

### 12. إدارة المعدات (Equipment)

**لوحة الإدارة:**
- سجل المعدات (الاسم، الرقم، التصنيف: مصاعد/إطفاء/بوابات/مراقبة/مياه وصرف/كهرباء/تدفئة)
- معلومات المعدات: العلامة التجارية، الطراز، موقع التركيب، تاريخ التركيب، انتهاء الضمان، العمر التصميمي
- سجلات الصيانة: فحص يومي/صيانة دورية/إصلاح أعطال/صيانة كبرى/استبدال
- فني الصيانة، الرسوم، جهة الصيانة، تاريخ الصيانة القادمة

### 13. الشكاوى والاقتراحات (Complaint)

**لوحة الإدارة:**
- قائمة الشكاوى (تصفية حسب النوع/الحالة)
- معالجة الشكوى (تخصيص المعالج، تعبئة ملاحظات المعالجة)
- تسجيل المتابعة (ملاحظات المتابعة، سجل الرضا)

**بوابة الملاك:**
- قائمة شكاوى/اقتراحاتي
- تقديم شكوى/اقتراح (النوع: شكوى/اقتراح/مدح، التصنيف: خدمة/بيئة/أمان/مرافق/ضجيج/بناء مخالف)
- دعم التقديم المجهول ورفع الصور
- عرض تقدم المعالجة
- تقييم الرضا

### 14. إدارة الزوار (Visitor)

**لوحة الإدارة:**
- الموافقة على حجوزات الزوار
- الاستعلام عن سجلات الزوار

**بوابة الملاك:**
- حجز زوار (اسم الزائر، الهاتف، الهوية، رقم اللوحة، عدد المرافقين، سبب الزيارة، الوقت المتوقع)
- توليد رمز المرور
- تعديل/إلغاء الحجز

### 15. إدارة العقود (Contract)

**لوحة الإدارة:**
- قائمة العقود (تصفية حسب النوع/الحالة)
- أنواع العقود: عقد عقارات/عقد إيجار/عقد صيانة/عقد خدمات/عقد شراء
- معلومات العقد: الرقم، الطرفان، المبلغ، تاريخا البدء والانتهاء، تاريخ التوقيع، المرفقات
- الحالة: مسودة/قيد التنفيذ/منتهي/مُنهى/مُجدد

### 16. الإدارة المالية (Finance)

**لوحة الإدارة:**
- إدارة الإيرادات (رسوم العقار/رسوم المواقف/الإيجار/رسوم الإعلان/صندوق الصيانة/أخرى)
- إدارة المصروفات (القوى العاملة/شراء المعدات/الصيانة/الطاقة/النظافة والمساحات الخضراء/المكتبية/الضرائب/أخرى)
- تقارير إحصاءات الإيرادات والمصروفات (شهرية/ربع سنوية/سنوية)

## الدفعة الثالثة: الوظائف المتقدمة

### 17. الدوريات الأمنية (Security Patrol)

**لوحة الإدارة:**
- إدارة مسارات الدوريات (إحداثيات المسار، نقاط التسجيل)
- سجلات الدوريات (وقتا البدء/الانتهاء، المدة، ملاحظات الشذوذ)
- إحصاءات نسبة اكتمال الدوريات

### 18. إدارة النظافة (Cleaning)

**لوحة الإدارة:**
- إدارة مناطق النظافة (الموقع، المساحة، التردد: يومي/أسبوعي/نصف شهري/شهري)
- سجلات النظافة (وقت التنظيف، الفاحص، ملاحظات الفحص، صور الموقع)
- إحصاءات نسبة اكتمال النظافة

### 19. إدارة المساحات الخضراء (Green)

**لوحة الإدارة:**
- إدارة المناطق الخضراء (الموقع، المساحة، النباتات الرئيسية)
- سجلات الصيانة (سقاية/تقليم/تسميد/مكافحة آفات/إعادة زراعة، الرسوم)

### 20. أنشطة المجتمع (Activity)

**لوحة الإدارة:**
- إدارة الأنشطة (العنوان، المحتوى، التصنيف: ثقافي رياضي/مناسبات/خيري/محاضرات/عائلي)
- صورة الغلاف، المكان، الحد الأقصى للمشاركين، الوقت، الرسوم
- الحالة: مفتوح للتسجيل/قيد التنفيذ/منتهي/ملغى
- عرض قائمة التسجيلات

**بوابة الملاك:**
- قائمة الأنشطة (تصفية: مفتوح للتسجيل/قيد التنفيذ)
- تفاصيل النشاط
- التسجيل للمشاركة/إلغاء التسجيل

### 21. إدارة استهلاك الطاقة (Energy)

**لوحة الإدارة:**
- إدارة العدادات (عداد كهرباء/مياه/غاز/تدفئة، الرقم)
- سجلات القراءة (القراءة الحالية، الاستهلاك، السعر الوحدوي، الرسوم)
- توليد الفواتير المرتبطة تلقائيًا

### 22. إدارة الموظفين (Staff)

**لوحة الإدارة:**
- معلومات الموظف (الاسم، رقم الهاتف مشفر، الهوية مشفرة، المنصب، القسم، تاريخ التوظيف)
- الأقسام: إدارة/خدمة عملاء/هندسة/أمن/نظافة/مساحات خضراء/مالية
- الحالة: على رأس العمل/مغادر/إجازة

## تصور اللوحات والتصدير

### لوحات القيادة

**لوحة قيادة لوحة الإدارة:**
- بطاقات المؤشرات الأساسية: إجمالي المستحق، إجمالي المحصل، نسبة المتأخرات، نسبة الإشغال
- مخطط خط اتجاه الرسوم (شهري/ربع سنوي)
- مخطط دائري لتوزيع أنواع الرسوم
- إحصاءات الإصلاح (حسب التصنيف، حسب الحالة)
- إحصاءات الشكاوى
- أحدث سجلات العمليات

**الصفحة الرئيسية لبوابة الملاك:**
- عدد عقاراتي، المبلغ المستحق، عدد طلبات الإصلاح قيد المعالجة، أحدث الإعلانات

### تصدير Excel

- تصدير قائمة الملاك
- تصدير تقارير الفواتير
- تصدير سجلات الدفع
- تصدير التقارير المالية
- إخفاء تلقائي للبيانات الحساسة عند التصدير

### تصدير PDF

- تصدير تصور لوحة القيادة
- التقارير المالية PDF (حقوق نشر في رأس الصفحة + علامة مائية غير قابلة للإزالة في التذييل)
- تخطيط A4 أفقي

## الميزات عبر الوحدات

| الميزة | الوصف |
|------|------|
| حماية المعرّفات | كل معرّفات الواجهات تُنقل مشفرة بتشفير hashids |
| تشفير البيانات | الحقول الحساسة (هاتف/بريد/هوية) طبقة API AES-256-CBC، طبقة القاعدة encryptable |
| تدقيق العمليات | كل عمليات POST/PUT/DELETE للمسؤول تُسجل تلقائيًا، شاملة الكشف التلقائي للطرف المصدر |
| التحكم بالصلاحيات | دقة RBAC method.path، معرف المدير الأعلى * |
| حماية تحديد المعدل | نافذة منزلقة في Redis، الدخول 10 مرات/دقيقة، التسجيل 5 مرات/دقيقة |
| رمز التحقق | رمز تحقق صيني بالنقر، إلزامي في تسجيل الدخول/التسجيل |
| الحذف الناعم | الملاك والمجمعات والعقارات والإعلانات تدعم الحذف الناعم |
| التدويل | ثنائي اللغة صيني/إنجليزي، PHP symfony/translation + Flutter GetX Translations، الافتراضي صيني والانحدار إنجليزي |
| توثيق API | توليد تلقائي `hg/apidoc`، 57 من 58 متحكمًا بشروح مجمعة في 10 مجموعات (Base/Docs/Install غير مجمعة)، `/apidoc/config` يقدم واجهة الإعداد |
| الاختبارات | سير TDD، 133 اختبارًا/465 تأكيدًا، service 100% نجاح، flutter analyze بلا مشاكل |
| Flutter Web | 13 صفحة (دخول/رئيسية/رسوم/إصلاح/مركز شخصي وغيرها)، نمط سطح مكتب PC، إدارة حالة GetX |
| HarmonyOS | هيكل مشروع كامل، طبقة خدمات ArkTS + مصادقة + دخول/رئيسية، @ohos.net.http |

## الوظائف الموسعة (الدفعة الرابعة)

### مركز إشعارات الرسائل
- قوالب إشعارات قابلة للتكوين (دفع التطبيق/رسائل SMS/بريد)
- إشعارات تلقائية لتذكير الفواتير وتقدم الإصلاح ونشر الإعلانات
- قائمة رسائل بوابة الملاك + إدارة القراءة

### محرك سير عمل الموافقات
- أنواع وخطوات موافقة قابلة للتكوين (مشرف←مدير←مدير عام)
- إرسال عمالة الإصلاح/موافقات الزوار/موافقات العقود عبر سير موحد
- سجلات الموافقات قابلة للتتبع

### تكامل الدفع
- إدارة طلبات دفع WeChat/Alipay
- معالجة استدعاءات الدفع، الاسترداد، إحصاءات التسوية
- تحديث تلقائي للفواتير المرتبطة

### تصويت/اقتراع الملاك
- تصويت عام + اقتراع جمعية الملاك (مرجح بالمساحة)
- إدارة الخيارات، سجلات التصويت، فرز تلقائي
- إحصاءات نسبة المشاركة

### ترقية SLA التلقائية للإصلاح
- تكوين مواعيد الاستجابة/الحل حسب التصنيف + درجة الاستعجال
- التجاوز يرقى تلقائيًا إلى الدور الأعلى
- تسجيل غرامات التأخير تلقائيًا

### التحصيل الذكي
- تكوين استراتيجيات تحصيل متدرجة (أيام التأخير←إجراء)
- مطابقة تلقائية للفواتير المتأخرة وتنفيذ التحصيل (تطبيق/رسائل SMS/هاتف/زيارة)
- حساب غرامات التأخير تلقائيًا

### التفتيش المتنقل
- توزيع مهام التفتيش (مسار GPS + نقاط فحص)
- تسجيل من الجوال (تحديد الموقع + تصوير + وضع علامات الشذوذ)
- إحصاءات نسبة اكتمال التفتيش

### متجر المجتمع
- إدارة تصنيفات/رفع/إخفاء المنتجات
- تصفح الملاك + تقديم الطلبات + تتبع الطلبات
- إدارة الشحن/الاسترداد

### التعرف على الوجوه
- تسجيل وجوه الملاك (ربط بخدمة التعرف من طرف ثالث)
- مراجعة ومصادقة لوحة الإدارة
- الربط بمرور البوابات

### إدارة مجموعة المجمعات المتعددة
- ربط متعدد إلى متعدد مجموعة←مجمع
- تجميع البيانات عبر المجمعات (عرض موحد للعقارات/الملاك/التحصيل)

### الأسئلة والأجوبة الذكية
- إدارة قاعدة المعرفة (تصنيفات/مقالات/كلمات مفتاحية)
- مطابقة تلقائية لأسئلة الملاك
- سجلات المحادثة + إحصاءات نسبة الحل

### شاشة البيانات الكبيرة
- تصور لحظي كامل الشاشة لبيانات العقارات
- أربع لوحات: التحصيل/الإصلاح/المعدات/الطاقة
- تحديث تلقائي بالتناوب
