# نظام إدارة العقارات (Property Management Platform)

[العربية](../ar/README.md) | [中文](../../../README.md)

> Copyright (c) 2026 erik <erik@erik.xyz> — https://erik.xyz

نظام إدارة عقارات متكامل، يغطي 22 وحدة أعمال + 12 وظيفة موسعة (إشعارات الرسائل/سير عمل الموافقات/الدفع/التصويت/SLA/شاشة البيانات الكبيرة/التحصيل/التفتيش/المتجر/الوجوه/المجموعة/الأسئلة الذكية). لوحة الإدارة (admin) وبوابة الملاك (service) منشورتان بشكل منفصل، وتغطي الواجهات Flutter Web (بنمط لوحة إدارة PC) وطرف HarmonyOS للجوال.

## مجموعة التقنيات

### الخلفية
- **الإطار**: webman v2 (workerman/webman)
- **اللغة**: PHP 8.3+
- **قاعدة البيانات**: MySQL 8.0+، بادئة الجداول `management_`، مفتاح أساسي BIGINT غير تلقائي التزايد
- **محرك البحث**: Elasticsearch 8.x
- **الذاكرة المؤقتة**: Redis 7.x

### التبعيات الأساسية
| اسم الحزمة | الاستخدام |
|------|------|
| `erikwang2013/snowflake-php` | توليد المفاتيح الأساسية BIGINT الفريدة عالميًا |
| `erikwang2013/hashids` | تشفير/فك تشفير معرّفات طبقة API |
| `erikwang2013/jwt-webman` | مصادقة JWT (HS256) |
| `erikwang2013/encryption` | تشفير البيانات الحساسة AES-256-CBC في نقل API |
| `erikwang2013/encryptable` | تشفير/فك تشفير الحقول الحساسة في قاعدة البيانات |
| `erikwang2013/webman-scout` | مزامنة بيانات Elasticsearch والبحث النصي الكامل |
| `erikwang2013/season` | بيانات أعلام الدول |
| `erikwang2013/security-php` | كشف أدوات الأمان |
| `erikwang2013/poster-php` | رمز تحقق عشوائي للعمليات الحساسة |
| `phpoffice/phpspreadsheet` | تصدير Excel |
| `barryvdh/laravel-dompdf` | تصدير PDF |
| `hg/apidoc` | توليد وثائق واجهات API تلقائيًا |

### الواجهات
- **Flutter 3.x** + GetX (شامل i18n) + Dio + fl_chart — لوحة إدارة ويب بنمط PC
- **HarmonyOS ArkTS** + @ohos.net.http — تطبيق الجوال

### توثيق API

كل نقاط API ومعاملاتها موضحة في الوثيقة المستقلة [docs/API.md](../../../docs/API.md). بعد تشغيل الخدمة يمكن أيضًا زيارة الوثائق التفاعلية المولدة تلقائيًا عبر apidoc:

| الطرف | العنوان | المجموعات |
|----|------|------|
| لوحة الإدارة | `http://localhost:8787/apidoc` | 10 مجموعات (common/dashboard/system/property-core/property-aux/property-adv/extensions/export/import/upload) |
| بوابة الملاك | `http://localhost:8788/apidoc` | 9 مجموعات (واجهات عامة/رئيسية/رسوم/إصلاح/تغذية راجعة/مواقف/أنشطة/شخصية/موسعة) |

### التدويل

- **خلفية PHP**: symfony/translation، ملفات اللغة في `resource/translations/{zh_CN,en}/messages.php`
- **Flutter Web**: GetX `Translations`، `apps/flutter/lib/i18n/messages.dart`
- **اللغة الافتراضية**: الصينية المبسطة (zh_CN)، تدعم التبديل إلى الإنجليزية (en)
- **ترويسة الطلب**: دعم التحكم بلغة الاستجابة عبر ترويسة `Accept-Language`

## بدء سريع

### الطريقة الأولى: معالج التثبيت عبر الويب (موصى به)

بعد تشغيل لوحة الإدارة زُر `http://localhost:8787/install`، وأكمل إعداد قاعدة البيانات وإنشاء حساب المسؤول عبر الواجهة.

```bash
cd admin
cp .env.example .env
composer install
php start.php start -d
# زُر http://localhost:8787/install لإكمال التثبيت
```

التفاصيل في [دليل التثبيت](../../../docs/INSTALL.md).

### الطريقة الثانية: التثبيت اليدوي

#### متطلبات البيئة

- PHP 8.1+
- MySQL 8.0+
- Redis 6.0+
- Composer 2.x
- Flutter SDK 3.x (تطوير الواجهات)

#### 1. تهيئة قاعدة البيانات

```bash
mysql -u root -e "CREATE DATABASE IF NOT EXISTS management DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root management < docs/install.sql
```

#### 2. تشغيل لوحة الإدارة

```bash
cd admin
cp .env.example .env
# عدّل .env: كلمة مرور قاعدة البيانات وغيرها
composer install
php start.php start -d
# لوحة الإدارة تعمل على http://localhost:8787
```

### 3. تشغيل بوابة الأعمال

```bash
cd service
cp .env.example .env
# عدّل .env: كلمة مرور قاعدة البيانات وغيرها
composer install
php start.php start -d
# بوابة الأعمال تعمل على http://localhost:8788
```

### 4. تشغيل الواجهات (تطوير)

```bash
cd apps/flutter
flutter pub get
flutter run -d chrome
```

### 5. تشغيل الاختبارات

```bash
# اختبارات لوحة الإدارة
cd admin && php vendor/bin/phpunit

# اختبارات بوابة الأعمال
cd service && php vendor/bin/phpunit
```

| المشروع | عدد الاختبارات | عدد التأكيدات | نسبة النجاح |
|------|--------|--------|--------|
| admin | 90 | 217 | 100% |
| service | 43 | 248 | 100% (1 متخطى) |
| **الإجمالي** | **133** | **465** | — |

تغطية اختبارات service: Snowflake ID، تشفير/فك Hashids، تنسيق الاستجابة، Schema قاعدة البيانات، ملفات ترجمة i18n

### النشر عبر Docker

```bash
cd admin
cp .env.docker .env
docker-compose up -d
# يشمل Nginx + PHP + MySQL + Redis + Elasticsearch
```
