## Web इंस्टॉल विज़ार्ड (अनुशंसित)

परियोजना में Web इंस्टॉल विज़ार्ड अंतर्निहित है, एडमिन पैनल प्रारंभ करने के बाद ब्राउज़र से सभी कॉन्फ़िगरेशन पूरे किए जा सकते हैं।

### उपयोग चरण

```bash
# 1. एडमिन पैनल निर्देशिका में जाएं
cd admin

# 2. पर्यावरण चर फ़ाइल बनाएं (टेम्पलेट से कॉपी करें)
cp .env.example .env

# 3. निर्भरताएँ इंस्टॉल करें
composer install --no-dev --optimize-autoloader

# 4. सेवा प्रारंभ करें
php start.php start -d
```

### 5. इंस्टॉल विज़ार्ड खोलें

ब्राउज़र में **`http://localhost:8787/install`** खोलें, संकेतों के अनुसार तीन-चरणीय कॉन्फ़िगरेशन पूरा करें:

| चरण | सामग्री | विवरण |
|------|------|------|
| चरण 1 | डेटाबेस कॉन्फ़िगरेशन | होस्ट、पोर्ट、डेटाबेस नाम、उपयोगकर्ता नाम、पासवर्ड भरें |
| चरण 2 | एडमिन खाता | बैकएंड लॉगिन उपयोगकर्ता नाम और पासवर्ड सेट करें (कम से कम 6 अक्षर) |
| चरण 3 | इंस्टॉलेशन पुष्टि | कॉन्फ़िग जानकारी जांचें, पुष्टि क्लिक करने पर इंस्टॉलेशन स्वचालित रूप से निष्पादित होता है |

इंस्टॉलेशन प्रक्रिया स्वचालित रूप से पूरी करती है:
1. डेटाबेस कनेक्शन परीक्षण
2. `.env` कॉन्फ़िगरेशन फ़ाइल लिखना
3. सभी 65 डेटा टेबल + अनुमति सीड इम्पोर्ट करना
4. एडमिन खाता बनाना और सुपर एडमिन भूमिका प्रदान करना
5. इंस्टॉल लॉक फ़ाइल `public/.installed` बनाना

### इंस्टॉलेशन के बाद

- एडमिन बैकएंड पता: `http://localhost:8787/admin`
- इंस्टॉल विज़ार्ड लॉगिन पता और खाता जानकारी दिखाएगा
- कॉन्फ़िग प्रभावी करने के लिए सेवा पुनरारंभ करने की सलाह: `php start.php restart -d`
- पुनः इंस्टॉल करने के लिए, `public/.installed` फ़ाइल हटाएं

## मैन्युअल इंस्टॉलेशन

### पर्यावरण आवश्यकताएँ

| घटक | संस्करण आवश्यकता | विवरण |
|------|---------|------|
| PHP | 8.1+ (अनुशंसित 8.3) | pcntl、pdo_mysql、redis、gd、mbstring एक्सटेंशन आवश्यक |
| MySQL | 8.0+ | utf8mb4 वर्ण सेट |
| Redis | 6.0+ | कैश、रेट लिमिट、Session |
| Composer | 2.x | PHP निर्भरता प्रबंधन |
| Elasticsearch | 8.x | फुल-टेक्स्ट खोज (वैकल्पिक, अक्षम करने पर डेटाबेस क्वेरी उपयोग होती है) |
| Flutter SDK | 3.x | केवल फ्रंटएंड विकास के लिए |

### PHP एक्सटेंशन जांच

```bash
php -m | grep -E "pcntl|pdo_mysql|redis|gd|mbstring|curl|json|xml|dom"
```

## डेटाबेस आरंभीकरण

### 1. डेटाबेस बनाएं

```bash
mysql -u root -p <<SQL
CREATE DATABASE IF NOT EXISTS property_management
  DEFAULT CHARSET utf8mb4
  COLLATE utf8mb4_unicode_ci;
SQL
```

### 2. मर्ज इंस्टॉल स्क्रिप्ट इम्पोर्ट करें

```bash
mysql -u root -p property_management < docs/install.sql
```

`docs/install.sql` में सभी 65 टेबल + RBAC अनुमति सीड डेटा शामिल है, `CREATE TABLE IF NOT EXISTS` का उपयोग करके बार-बार निष्पादन योग्य सुनिश्चित करता है।

निष्पादन के बाद सत्यापन:

```bash
mysql -u root -p property_management -e "SHOW TABLES;" | wc -l
# आउटपुट होना चाहिए: 66 (65 टेबल + 1 पंक्ति हेडर)
```

## एडमिन पैनल तैनाती

एडमिन पैनल `http://localhost:8787` पर चलता है, एडमिन बैकएंड API प्रदान करता है।

```bash
cd admin

# 1. पर्यावरण चर कॉन्फ़िगर करें
cp .env.example .env
# .env संपादित करें, डेटाबेस पासवर्ड、JWT कुंजी आदि बदलें

# 2. निर्भरताएँ इंस्टॉल करें
composer install --no-dev --optimize-autoloader

# 3. सेवा प्रारंभ करें
php start.php start -d
# -d बैकग्राउंड निष्पादन दर्शाता है, -d के बिना फोरग्राउंड में चलाकर लॉग देखे जा सकते हैं

# 4. सत्यापन
curl http://localhost:8787/health
```

### मुख्य कॉन्फ़िग आइटम (admin/.env)

| कॉन्फ़िग आइटम | विवरण | प्रोडक्शन आवश्यकता |
|--------|------|-------------|
| `JWT_SECRET_KEY` | JWT हस्ताक्षर कुंजी | 64 अक्षर से अधिक यादृच्छिक स्ट्रिंग |
| `HASHIDS_SALT` | ID एन्क्रिप्शन सॉल्ट मान | यादृच्छिक स्ट्रिंग, service से समान रखें |
| `SNOWFLAKE_DATACENTER_ID` | डेटा सेंटर ID (0-31) | बहु-डेटासेंटर तैनाती में अलग करना आवश्यक |
| `SNOWFLAKE_WORKER_ID` | वर्कर नोड ID (0-31) | एक ही डेटासेंटर में हर मशीन अलग |
| `ENCRYPTION_KEY` | API ट्रांसमिशन एन्क्रिप्शन कुंजी | 32 बाइट यादृच्छिक स्ट्रिंग |
| `ENCRYPTABLE_KEY` | डेटाबेस फ़ील्ड एन्क्रिप्शन कुंजी | 32 बाइट यादृच्छिक स्ट्रिंग |
| `DB_PASSWORD` | डेटाबेस पासवर्ड | मजबूत पासवर्ड |

## व्यवसाय पोर्टल तैनाती

व्यवसाय पोर्टल `http://localhost:8788` पर चलता है, मालिक पोर्टल API प्रदान करता है।

```bash
cd service

# 1. पर्यावरण चर कॉन्फ़िगर करें
cp .env.example .env
# .env संपादित करें, डेटाबेस पासवर्ड、JWT कुंजी आदि बदलें

# 2. निर्भरताएँ इंस्टॉल करें
composer install --no-dev --optimize-autoloader

# 3. सेवा प्रारंभ करें
php start.php start -d

# 4. सत्यापन
curl http://localhost:8788/health
```

> **ध्यान दें:** admin और service एक ही डेटाबेस साझा करते हैं। `HASHIDS_SALT` admin से समान रहना चाहिए, अन्यथा admin द्वारा जनरेट की गई एन्क्रिप्टेड ID service पोर्टल पर डिक्रिप्ट नहीं हो सकेगी।

## Docker तैनाती

### एडमिन पैनल

```bash
cd admin
cp .env.docker .env
# .env संपादित करके प्रोडक्शन कुंजियाँ बदलें

docker compose up -d
# शामिल: Nginx + PHP + MySQL + Redis + Elasticsearch
```

### व्यवसाय पोर्टल

```bash
cd service
cp .env.docker .env
# .env संपादित करके प्रोडक्शन कुंजियाँ बदलें

docker compose up -d
```

### सेवा पोर्ट योजना

| सेवा | admin | service | विवरण |
|------|-------|---------|------|
| एप्लिकेशन | 8787 | 8788 | webman HTTP |
| MySQL | 3306 | 3307 | कंटेनर पोर्ट मैपिंग |
| Redis | 6379 | 6380 | कंटेनर पोर्ट मैपिंग |
| Elasticsearch | 9200 | 9201 | कंटेनर पोर्ट मैपिंग |
| Nginx | 80/443 | 80/443 | अलग-अलग तैनाती आवश्यक |

> एक ही होस्ट पर दो docker-compose तैनात करते समय, service के पोर्ट पूर्व-निर्धारित ऑफसेट के साथ संघर्ष से बचते हैं।

## सामान्य समस्याएँ

### प्रश्न: प्रारंभ में त्रुटि `Call to undefined function pcntl_fork()`

PHP में pcntl एक्सटेंशन नहीं है।

```bash
# Ubuntu/Debian
apt install php-pcntl

# Docker
docker-php-ext-install pcntl
```

### प्रश्न: लॉगिन के बाद Token अमान्य बताता है

जांचें कि admin और service के `.env` में निम्न कॉन्फ़िग समान हैं या नहीं:
- `JWT_SECRET_KEY`
- `JWT_ALGORITHM`

### प्रश्न: एन्क्रिप्टेड ID दोनों पोर्टलों पर असंगत

सुनिश्चित करें कि admin और service का `HASHIDS_SALT` मान बिल्कुल समान है।

### प्रश्न: Docker कंटेनरों के बीच नेटवर्क नहीं चलता

IP के बजाय कंटेनर नाम से कनेक्ट करें (जैसे `DB_HOST=mysql`)।

### प्रश्न: डेटाबेस कैसे रीसेट करें

```bash
mysql -u root -p -e "DROP DATABASE IF EXISTS property_management;"
mysql -u root -p -e "CREATE DATABASE property_management DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p property_management < docs/install.sql
```

### प्रश्न: HTTPS कैसे कॉन्फ़िगर करें

प्रोडक्शन में Nginx रिवर्स प्रॉक्सी से TLS समाप्त करने की सलाह दी जाती है। संदर्भ कॉन्फ़िग `admin/docs/nginx-security.conf` में देखें।
