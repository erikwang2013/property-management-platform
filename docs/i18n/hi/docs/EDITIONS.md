## फ़ंक्शन मॉड्यूल तुलना

### आधार संस्करण (Lite)

मुख्य संपत्ति प्रबंधन, एडमिन बैकएंड सामान्य प्रणाली + 10 मुख्य व्यवसाय मॉड्यूल शामिल।

**एडमिन पैनल**: डैशबोर्ड、उपयोगकर्ता/भूमिका/अनुमति/कॉन्फ़िग/लॉग CRUD、समुदाय/भवन/इकाई/रूम प्रकार/संपत्ति/मालिक/किरायेदार/शुल्क/मरम्मत/घोषणा CRUD

**मालिक पोर्टल**: पंजीकरण/लॉगिन、होम、मेरी संपत्तियाँ、बिल भुगतान、मरम्मत सबमिट/रेटिंग、घोषणा देखना、व्यक्तिगत जानकारी

### मानक संस्करण (Standard)

आधार संस्करण के ऊपर 6 सहायक व्यवसाय मॉड्यूल + पैनल विज़ुअलाइज़ेशन + डेटा निर्यात जोड़े गए।

**एडमिन पैनल नया**: पार्किंग स्थल/वाहन CRUD、उपकरण रजिस्टर+रखरखाव、शिकायत प्रसंस्करण+फॉलो-अप、अतिथि अनुमोदन、अनुबंध प्रबंधन、आय-व्यय प्रबंधन+सांख्यिकी

**मालिक पोर्टल नया**: मेरे वाहन/पार्किंग स्थल、पार्किंग रिकॉर्ड、अतिथि आरक्षण/पास कोड

### पूर्ण संस्करण (Full)

**एडमिन पैनल नया**: गश्त मार्ग+रिकॉर्ड、सफाई क्षेत्र+रिकॉर्ड、हरियाली क्षेत्र+रखरखाव、सामुदायिक गतिविधि प्रबंधन、ऊर्जा मीटर+रीडिंग、कर्मचारी प्रबंधन、सूचना टेम्पलेट+भेजना、अनुमोदन इंजन、भुगतान ऑर्डर+रिफंड、मतदान प्रबंधन+SLA नियम+वसूली रणनीति+निरीक्षण कार्य+मॉल प्रबंधन+चेहरा समीक्षा+समूह प्रबंधन+ज्ञान आधार

**मालिक पोर्टल नया**: सामुदायिक गतिविधि पंजीकरण、पार्किंग/अतिथि आरक्षण、संदेश सूचना、मतदान+मतगणना、उत्पाद ब्राउज़+ऑर्डर、स्मार्ट प्रश्नोत्तर、चेहरा पंजीकरण

## डेमो प्रवाह

**तैयारी**: `docs/install.sql` निष्पादित किया गया (पूर्ण टेबल संरचना, सभी संस्करणों की टेबल सहित); `admin/.env` में डेटाबेस कनेक्शन कॉन्फ़िगर किया गया। संस्करण अंतर रूट पंजीकरण और फ़ंक्शन दृश्यता में है, टेबल संरचना पूर्ण और एकीकृत है।

### आधार संस्करण (Lite)

1. डेमो डेटा निष्पादित करें: `cd admin && php ../scripts/demo_data.php` (आइडेम्पोटेंट, बार-बार निष्पादित किया जा सकता है)
2. डेमो डेटा दायरा: समुदाय/भवन/इकाई/रूम प्रकार/संपत्ति/मालिक/किरायेदार/शुल्क/बिल/घोषणा + डेमो खाता, Lite मुख्य मॉड्यूल को कवर करता है
3. क्या देखें: एडमिन पैनल डैशबोर्ड + उपयोगकर्ता/भूमिका/अनुमति/कॉन्फ़िग/लॉग + संपत्ति/मालिक/किरायेदार/शुल्क/मरम्मत/घोषणा CRUD; मालिक पोर्टल पंजीकरण/लॉगिन、होम、मेरी संपत्तियाँ、बिल भुगतान、मरम्मत、घोषणा
4. रूट अंतर: केवल Lite समूह पंजीकृत, `edition_supports('standard'/'full')` से लिपटे ब्लॉक पंजीकृत नहीं होते (`admin/config/route.php`)

### मानक संस्करण (Standard)

1. डेमो डेटा निष्पादित करें: `cd admin && php ../scripts/demo_data.php` (आइडेम्पोटेंट, दोहराव केवल कमी पूरी करता है, डुप्लिकेट नहीं बनाता)
2. सहायक मॉड्यूल डेटा कम है, पार्किंग/उपकरण/शिकायत/अतिथि/अनुबंध/आय-व्यय डेमो में थोड़ा दर्ज करना पर्याप्त है
3. क्या देखें: एडमिन पैनल नया पार्किंग स्थल/वाहन、उपकरण रजिस्टर+रखरखाव、शिकायत प्रसंस्करण+फॉलो-अप、अतिथि अनुमोदन、अनुबंध प्रबंधन、आय-व्यय प्रबंधन+सांख्यिकी; मालिक पोर्टल नया मेरे वाहन/पार्किंग स्थल、पार्किंग रिकॉर्ड、अतिथि आरक्षण/पास कोड
4. रूट अंतर: `edition_supports('standard')` समूह जोड़ा गया, Lite समूह बरकरार

### पूर्ण संस्करण (Full)

1. डेमो डेटा निष्पादित करें: `cd admin && php ../scripts/demo_data.php` (आइडेम्पोटेंट)
2. उन्नत मॉड्यूल (भुगतान/अनुमोदन/मतदान/मॉल/निरीक्षण/चेहरा/समूह/ज्ञान आधार) डेमो डेटा आवश्यकतानुसार दर्ज करें, या डेमो खाते से सीधे डेटा बनाएं
3. क्या देखें: Standard के ऊपर नया गश्त/सफाई/हरियाली/ऊर्जा/कर्मचारी/सूचना टेम्पलेट/अनुमोदन इंजन/भुगतान ऑर्डर/मतदान/SLA/वसूली/निरीक्षण/मॉल/चेहरा/समूह/ज्ञान आधार; मालिक पोर्टल गतिविधि पंजीकरण、संदेश सूचना、मतदान、मॉल ऑर्डर、स्मार्ट प्रश्नोत्तर、चेहरा पंजीकरण
4. रूट अंतर: पूर्ण पंजीकरण, `edition_supports('full')` समूह प्रभावी (`admin/config/route.php`)

### संस्करण स्विच करना

```bash
# admin/.env में लक्ष्य संस्करण सेट करें (क्रमशः संचयी, full में सभी सुविधाएँ शामिल)
EDITIONS=lite|standard|full

# webman पुनरारंभ करें (कंटेनर तैनाती: docker compose restart app；बेयर मेटल: php start.php restart)
```

- कॉन्फ़िग fail-fast: `EDITIONS` मान अमान्य होने पर सीधे त्रुटि फेंकी जाती है (`admin/config/edition.php`), गलत संस्करण में मौन रोलबैक नहीं होता।
- डेमो डेटा स्क्रिप्ट आइडेम्पोटेंट है, संस्करण स्विच के लिए डेटाबेस साफ़ करने की आवश्यकता नहीं; Standard/Full मॉड्यूल डेटा कम है, वास्तविक व्यवसाय से दर्ज करना पर्याप्त है।
