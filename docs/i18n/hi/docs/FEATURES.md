## क्रॉस-फ़ंक्शन विशेषताएँ

### ID एन्क्रिप्टेड ट्रांसमिशन
सभी API इंटरफ़ेस अनुरोधों और प्रतिक्रियाओं में ID फ़ील्ड `erikwang2013/hashids` से एन्कोड/डिकोड होती हैं। क्लाइंट को hashid स्ट्रिंग मिलती है (जैसे `aB3xK9mW2pQ7rT5v`), बैकएंड BIGINT में डिकोड करके संचालन करता है।

### संवेदनशील डेटा सुरक्षा
- API ट्रांसमिशन परत: `erikwang2013/encryption` — AES-256-CBC
- डेटाबेस स्टोरेज परत: `erikwang2013/encryptable` — Eloquent Model casts स्वतः एन्क्रिप्ट/डिक्रिप्ट
- फ्रंटएंड प्रदर्शन परत: फोन नंबर 138****1234, ईमेल a***@e.com

### ऑपरेशन ऑडिट
सभी एडमिन पैनल POST/PUT/DELETE संचालन स्वचालित रूप से रिकॉर्ड होते हैं, इसमें संचालक उपयोगकर्ता、IP、पथ、पैरामीटर (मास्क किए गए)、संचालन समय、स्रोत प्लेटफ़ॉर्म (web/ios/android/harmonyos/windows/macos/linux/ipados) शामिल हैं।

### अनुमति नियंत्रण
- एडमिन पैनल: RBAC method.path स्तर प्राधिकरण, सुपर एडमिन `*` जांच छोड़ता है
- मालिक पोर्टल: JWT Bearer Token प्रमाणीकरण, मालिक केवल अपना डेटा संचालित कर सकता है

### सुरक्षा सुरक्षा
18-परत गहराई रक्षा: कैप्चा → पासवर्ड पुष्टि → यादृच्छिक सत्यापन → सुरक्षा स्कैन → हमला अवरोधन → ट्रांसमिशन एन्क्रिप्शन → JWT → सत्र नियंत्रण → खाता लॉक → RBAC → रेट लिमिट → ID सुरक्षा → अनुरोध एन्क्रिप्शन → स्टोरेज एन्क्रिप्शन → प्रदर्शन मास्किंग → ऑडिट → CSP → कॉपीराइट वॉटरमार्क

### निर्यात फ़ंक्शन
- Excel: PhpSpreadsheet, नीला बैकग्राउंड सफेद टेक्स्ट हेडर + पहली पंक्ति फ़्रीज़ + स्वतः फ़िल्टर + संवेदनशील डेटा मास्किंग
- PDF: Dompdf A4 लैंडस्केप, पेज हेडर कॉपीराइट + फुटर में हटाने योग्य नहीं कॉपीराइट वॉटरमार्क
- पैनल विज़ुअलाइज़ेशन डेटा PDF निर्यात

### सर्च इंजन
- `erikwang2013/webman-scout` Elasticsearch चलाता है
- स्वतः इंडेक्स सिंक (जोड़/हटाना/बदलना स्वतः पुश)
- इंडेक्स उपसर्ग `erik_`, डेटाबेस टेबल उपसर्ग के अनुरूप

### अंतर्राष्ट्रीयकरण (i18n)
- **PHP बैकएंड**: symfony/translation — `resource/translations/{zh_CN,en}/messages.php`, 42 अनुवाद कुंजियाँ, कंट्रोलर `__()` विधि से अनुवाद प्राप्त करता है
- **Flutter Web**: GetX `Translations` — `lib/i18n/messages.dart`, 101 अनुवाद कुंजियाँ, पेज `.tr` एक्सटेंशन से उपयोग करते हैं
- **HarmonyOS**: `resources/{base,en_US}/element/string.json` संसाधन क्वालिफायर
- **डिफ़ॉल्ट भाषा**: सरलीकृत चीनी (zh_CN), फॉलबैक भाषा अंग्रेज़ी (en)
- **अनुरोध हेडर**: `Accept-Language` से प्रतिक्रिया भाषा नियंत्रण समर्थित
