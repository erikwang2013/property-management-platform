## 八、तत्काल कार्रवाई सुझाव

✅ मूल P1 आइटम 1-4 (कुंजी सुदृढ़ीकरण → CI पूरक → बैकअप स्क्रिप्ट → ES डिग्रेड) सभी निष्पादित हो चुके हैं (P4-P9 पुनरावृत्त डिलीवरी)।

**शेष निर्भरता आइटम (बाहरी शर्तें आवश्यक, कोड अंतर नहीं)**:
1. भुगतान सैंडबॉक्स संयुक्त डिबगिंग: WECHAT_PAY_* / ALIPAY_* सैंडबॉक्स क्रेडेंशियल मिलने पर `scripts/payment_sandbox_smoke.php` चलाएं (ऑर्डर→डुप्लिकेट कॉलबैक आइडेमपोटेंसी→रिफंड→समाधान पूर्ण चेन सत्यापन)

3. बैकअप रिकवरी अभ्यास: docs/RECOVERY_RUNBOOK.md के अनुसार तिमाही अभ्यास करें और मापित समय रिकॉर्ड करें (RTO ≤ 1h लक्ष्य)
4. HarmonyOS वास्तविक डिवाइस सत्यापन: टेस्ट डिवाइस उपलब्ध होने पर मुख्य पाथ चलाएं (भुगतान/मरम्मत/घोषणा/अतिथि/पार्किंग)
