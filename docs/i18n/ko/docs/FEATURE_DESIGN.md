# 기능 설계 문서 (Feature Design)

> Copyright (c) 2026 erik <erik@erik.xyz> — https://erik.xyz

## 개요

부동산 관리 시스템은 **관리자측**（부동산 회사 내부 사용）과 **입주민 포털**（단지 입주민/임차인 사용）으로 나뉘며, 15개 비즈니스 모듈을 3개 배치로 인도합니다.

---

## 제1차: 핵심 비즈니스

### 1. 단지/커뮤니티 관리 (Community)

**관리자:**
- 단지 목록（검색, 페이징, 상태 필터）
- 단지 생성/조회/수정/삭제
- 단지 정보: 이름, 주소（시/도/구）, 건축 면적, 동 수, 세대 수, 시행사, 부동산 회사, 연락처
- 삭제 시 비밀번호 2차 확인 필요, 소프트 삭제 사용

**입주민 포털:** 관리 권한 불필요, 홈에서 연결된 단지 정보 표시.

### 2. 동 관리 (Building)

**관리자:**
- 단지별 동 목록 필터
- 동 생성/조회/수정/삭제
- 동 정보: 이름, 유형（타워형/판상형/빌라/상업）, 층수, 호 수, 엘리베이터 수, 준공 연도, 구조 유형
- 정렬 지원

### 3. 호 관리 (Unit)

**관리자:**
- 동별 호 목록 필터
- 호 생성/조회/수정/삭제
- 호 정보: 이름, 층별 세대 수

### 4. 세대 유형 관리 (RoomType)

**관리자:**
- 세대 유형 목록 CRUD
- 세대 유형 정보: 이름（3실 2거실）, 방/거실/욕실 수, 세대 도면

### 5. 부동산 관리 (Room)

**관리자:**
- 부동산 트리 뷰（단지→동→호→세대）
- 세대 생성/조회/수정/삭제
- 세대 정보: 호실 번호, 층, 세대 유형, 면적（전용/공용/총면적）, 방향, 인테리어, 용도（주거/상업/사무）, 상태（공실/판매 완료/임대/자가 거주）
- 입주민 일괄 연결/해제

**입주민 포털:**
- 연결된 부동산 목록 조회
- 부동산 상세 조회（면적, 방향, 세대 유형, 권리 정보）

### 6. 입주민 관리 (Owner)

**관리자:**
- 입주민 목록（검색, 페이징, 상태 필터）
- 입주민 생성/조회/수정/삭제
- 입주민 정보: 이름, 휴대폰 번호（암호화）, 이메일（암호화）, 주민등록번호（암호화）, 성별, 생일, 비상 연락처, 입주일
- 일괄 가져오기（Excel）, 일괄 활성/비활성화, 일괄 삭제
- 부동산 연결/해제

**입주민 포털:**
- 회원가입（휴대폰 번호+비밀번호+캡차, 부동산 연결 검증 가능）
- 로그인（휴대폰 번호+비밀번호+클릭 캡차, 계정 잠금 보호）
- 개인 정보 조회/수정
- 비밀번호 변경, 로그아웃

### 7. 임차인 관리 (Tenant)

**관리자:**
- 부동산/집주인별 임차인 목록 필터
- 임차인 생성/조회/수정/삭제
- 임차인 정보: 이름, 휴대폰 번호（암호화）, 주민등록번호（암호화）, 임대 시작/종료, 월 임대료, 상태

### 8. 요금 관리 (Fee)

**요금 유형（관리자）:**
- 요금 유형 CRUD: 관리비, 수도비, 전기비, 가스, 난방, 주차비, 수리 기금, 기타
- 단가, 과금 단위（원/m²/월, 원/톤, 원/도 등）, 과금 주기（매월/매분기/매년）, 필수 여부

**청구서 관리（관리자）:**
- 단지/동/부동산별 청구서 조회
- 수동 생성/수정 청구서
- 청구서 일괄 생성（단지+요금 유형+주기 선택 시 모든 세대에 자동 생성）
- 청구서 정보: 요금 유형, 금액, 연체료, 요금 주기, 마감일
- 상태: 미납/부분 납부/납부 완료/연체/면제
- 일괄 납부 독촉 알림

**청구서（입주민 포털）:**
- 내 청구서 목록（상태 필터: 미납/납부 완료/연체）
- 청구서 상세
- 온라인 납부（위챗/알리페이, 비밀번호 2차 확인 필요）
- 납부 기록 조회
- 요금 통계（연간·월간 추이, 요금 분류 비율）

**납부 기록（관리자）:**
- 납부 기록 조회
- 오프라인 수금 등록（현금/카드/은행 송금）

### 9. 수리 접수 관리 (Repair)

**관리자:**
- 수리 접수 목록（상태/분류 필터）
- 수리 접수 상세 조회
- 배정（수리기사 지정）
- 수리 진행 상황 업데이트

**입주민 포털:**
- 내 수리 접수 목록
- 수리 접수 제출（부동산 선택, 분류, 긴급도, 설명, 이미지 업로드, 예약 시간）
- 수리 접수 상세 및 진행 상황 조회
- 수리 접수 취소（배정 대기 상태만, 비밀번호 확인 필요）
- 수리 접수 평가（1-5점+텍스트 평가）

### 10. 공지 알림 (Announcement)

**관리자:**
- 공지 목록 CRUD
- 단지별 공지 발행
- 분류: 알림/공지/리마인더/활동
- 상단 고정, 초안/발행 상태

**입주민 포털:**
- 발행된 공지 목록 조회（분류 필터）
- 공지 상세

## 제2차: 보조 비즈니스

### 11. 주차 관리 (Parking)

**관리자:**
- 주차 공간 관리（번호, 지상/지하, 면적, 상태: 비어 있음/판매 완료/임대 중/수리 중）
- 차량 관리（차량 번호 암호화, 브랜드, 색상, 유형, 주차 공간/입주민 연결）
- 주차 기록 조회（입차/출차 시간, 주차 시간, 요금）

**입주민 포털:**
- 내 차량 목록
- 내 주차 공간 목록
- 주차 기록 조회

### 12. 장비 관리 (Equipment)

**관리자:**
- 장비 대장（이름, 번호, 분류: 엘리베이터/소방/출입 통제/CCTV/급배수/전기/난방 환기）
- 장비 정보: 브랜드, 모델, 설치 위치, 설치일, 보증 만료, 설계 수명
- 유지보수 기록: 일상 점검/정기 보수/고장 수리/대수리/교체
- 유지보수 담당자, 비용, 유지보수 업체, 다음 유지보수일

### 13. 민원·제안 (Complaint)

**관리자:**
- 민원 목록（유형/상태 필터）
- 민원 처리（처리 담당자 배정, 처리 메모 작성）
- 방문 회신 등록（회신 메모, 만족도 기록）

**입주민 포털:**
- 내 민원/제안 목록
- 민원/제안 제출（유형: 민원/제안/칭찬, 분류: 서비스/환경/안전/시설/소음/불법 건축）
- 익명 제출, 이미지 업로드 지원
- 처리 진행 상황 조회
- 만족도 평가

### 14. 방문객 관리 (Visitor)

**관리자:**
- 방문객 예약 승인
- 방문객 기록 조회

**입주민 포털:**
- 방문객 예약（방문객 이름, 전화, 주민등록번호, 차량 번호, 동행 인원, 방문 사유, 예상 시간）
- 출입 코드 생성
- 예약 수정/취소

### 15. 계약 관리 (Contract)

**관리자:**
- 계약 목록（유형/상태 필터）
- 계약 유형: 부동산 계약/임대 계약/유지보수 계약/서비스 계약/구매 계약
- 계약 정보: 번호, 갑을 당사자, 금액, 시작/종료일, 체결일, 첨부 파일
- 상태: 초안/이행 중/만료/종료/갱신

### 16. 재무 관리 (Finance)

**관리자:**
- 수입 관리（관리비/주차비/임대료/광고비/수리 기금/기타）
- 지출 관리（인건비/장비 구매/유지보수/에너지/청소·조경/사무/세금/기타）
- 수입·지출 통계 보고서（월간/분기/연간）

## 제3차: 고급 기능

### 17. 보안 순찰 (Security Patrol)

**관리자:**
- 순찰 경로 관리（경로 좌표, 출석 지점）
- 순찰 기록（시작/종료 시간, 소요 시간, 이상 메모）
- 순찰 완료율 통계

### 18. 청소 관리 (Cleaning)

**관리자:**
- 청소 구역 관리（위치, 면적, 빈도: 매일/매주/격주/매월）
- 청소 기록（청소 시간, 점검자, 점검 메모, 현장 사진）
- 청소 완료율 통계

### 19. 조경 관리 (Green)

**관리자:**
- 조경 구역 관리（위치, 면적, 주요 식물）
- 유지관리 기록（관수/전정/시비/방충/보식, 비용）

### 20. 커뮤니티 활동 (Activity)

**관리자:**
- 활동 관리（제목, 내용, 분류: 문화체육/명절/공익/강좌/가족）
- 표지 이미지, 장소, 최대 참가 인원, 시간, 비용
- 상태: 신청 중/진행 중/종료/취소
- 신청 목록 조회

**입주민 포털:**
- 활동 목록（필터: 신청 중/진행 중）
- 활동 상세
- 신청하기/신청 취소

### 21. 에너지 관리 (Energy)

**관리자:**
- 미터 관리（전기/수도/가스/난방 미터, 번호）
- 검침 기록（이번 수치, 사용량, 단가, 요금）
- 연동 청구서 자동 생성

### 22. 직원 관리 (Staff)

**관리자:**
- 직원 정보（이름, 휴대폰 번호 암호화, 주민등록번호 암호화, 직위, 부서, 입사일）
- 부서: 관리/고객 서비스/공사/보안/청소/조경/재무
- 상태: 재직/퇴사/휴가

## 패널 시각화와 내보내기

### 대시보드 패널

**관리자 대시보드:**
- 핵심 지표 카드: 총 수취 금액, 실수취 금액, 미납률, 입주율
- 요금 추이 꺾은선 그래프（월간/분기）
- 요금 분류 파이 차트
- 수리 접수 통계（분류별, 상태별）
- 민원 통계
- 최근 작업 로그

**입주민 포털 홈:**
- 내 부동산 수, 납부 대기 금액, 처리 중 수리 접수 수, 최신 공지

### Excel 내보내기

- 입주민 목록 내보내기
- 청구서 보고서 내보내기
- 납부 기록 내보내기
- 재무 보고서 내보내기
- 내보내기 시 민감 데이터 자동 마스킹

### PDF 내보내기

- 대시보드 패널 시각화 내보내기
- 재무 보고서 PDF（페이지 헤더 저작권 + 바닥글 제거 불가 저작권 워터마크）
- A4 가로 레이아웃

## 모듈 간 특성

| 특성 | 설명 |
|------|------|
| ID 보호 | 모든 인터페이스 ID는 hashids 인코딩으로 전송 |
| 데이터 암호화 | 민감 필드（휴대폰/이메일/주민등록번호）API 계층 AES-256-CBC, DB 계층 encryptable |
| 작업 감사 | 모든 관리자 POST/PUT/DELETE 작업 자동 기록, 출처측 자동 감지 포함 |
| 권한 제어 | RBAC method.path 세분화, 슈퍼 관리자 * 식별 |
| 속도 제한 | Redis 슬라이딩 윈도우, 로그인 10회/분, 회원가입 5회/분 |
| 캡차 | 클릭형 중국어 캡차, 로그인/회원가입 강제 |
| 소프트 삭제 | 입주민, 단지, 부동산, 공지 소프트 삭제 지원 |
| 국제화 | 중문/영문 이중 언어, PHP symfony/translation + Flutter GetX Translations, 기본 중국어, 폴백 영어 |
| API 문서 | `hg/apidoc` 자동 생성, 58개 컨트롤러 중 57개가 10개 그룹으로 주석（Base/Docs/Install 제외）, `/apidoc/config` 설정 API 제공 |
| 테스트 | TDD 흐름, 133개 테스트/465개 assertion, service 100% 통과, flutter analyze 문제 0건 |
| Flutter Web | 13개 페이지（로그인/홈/요금/수리 접수/개인 센터 등）, PC 데스크톱 스타일, GetX 상태 관리 |
| HarmonyOS | 완전한 프로젝트 스켈레톤, ArkTS 서비스 계층 + 인증 + 로그인/홈, @ohos.net.http |

## 확장 기능（제4차）

### 메시지 알림 센터
- 설정 가능한 알림 템플릿（App 푸시/문자/이메일）
- 청구서 알림, 수리 접수 진행, 공지 발행 자동 알림
- 입주민 포털 메시지 목록 + 읽음 관리

### 승인 워크플로 엔진
- 설정 가능한 승인 유형과 단계（팀장→매니저→총괄）
- 수리 접수 배정/방문객 승인/계약 승인 표준화된 흐름
- 승인 기록 추적 가능

### 결제 연동
- 위챗/알리페이 결제 주문 관리
- 결제 콜백 처리, 환불, 대사 통계
- 연동 청구서 자동 업데이트

### 입주민 투표/의결

- 선택지 관리, 투표 기록, 자동 집계
- 참여율 통계

### 수리 접수 SLA 자동 승격

- 초과 시 상위 역할로 자동 승격
- 초과 벌금 자동 기록

### 스마트 납부 독촉

- 연체료 자동 계산

### 순찰 모바일측

- 순찰 완료율 통계
