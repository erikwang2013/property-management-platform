## 기능 모듈 비교

### 기본판 (Lite)

핵심 부동산 관리, 관리 콘솔 공통 시스템 + 10개 핵심 비즈니스 모듈 포함.

**관리자**: 대시보드, 사용자/역할/권한/설정/로그 CRUD, 단지/동/호/세대 유형/부동산/입주민/임차인/요금/수리 접수/공지 CRUD

**입주민 포털**: 회원가입/로그인, 홈, 내 부동산, 청구서 납부, 수리 접수 제출/평가, 공지 조회, 개인 정보

---

### 표준판 (Standard)

기본판 위에 6개 보조 비즈니스 모듈 + 패널 시각화 + 데이터 내보내기 추가.

**관리자 추가**: 주차 공간/차량 CRUD, 장비 대장+유지보수, 민원 처리+방문 회신, 방문객 승인, 계약 관리, 수입·지출 관리+통계

**입주민 포털 추가**: 내 차량/주차 공간, 주차 기록, 방문객 예약/출입 코드

---

### 완전판 (Full)

표준판 위에 고급 모듈 + 12개 확장 기능 추가.

**관리자 추가**: 순찰 경로+기록, 청소 구역+기록, 조경 구역+유지관리, 커뮤니티 활동 관리, 에너지 미터+검침, 직원 관리, 알림 템플릿+발송, 승인 엔진, 결제 주문+환불, 투표 관리+SLA 규칙+독촉 전략+순찰 작업+쇼핑몰 관리+안면 심사+그룹 관리+지식 베이스

**입주민 포털 추가**: 커뮤니티 활동 신청, 주차/방문객 예약, 메시지 알림, 투표+집계, 상품 조회+주문, 스마트 Q&A, 안면 등록

## 데모 흐름

**준비**: `docs/install.sql` 실행 완료（전체 테이블 구조, 모든 버전의 테이블 포함）; `admin/.env`에 데이터베이스 연결 설정 완료. 버전 차이는 라우트 등록과 기능 가시성에 있으며, 테이블 구조는 전체로 통일.

### 기본판 (Lite)

1. 데모 데이터 실행: `cd admin && php ../scripts/demo_data.php`（멱등, 반복 실행 가능）
2. 데모 데이터 범위: 단지/동/호/세대 유형/부동산/입주민/임차인/요금/청구서/공지 + 데모 계정, Lite 핵심 모듈 커버
3. 볼 것: 관리자 대시보드 + 사용자/역할/권한/설정/로그 + 부동산/입주민/임차인/요금/수리 접수/공지 CRUD; 입주민 포털 회원가입/로그인, 홈, 내 부동산, 청구서 납부, 수리 접수, 공지
4. 라우트 차이: Lite 그룹만 등록, `edition_supports('standard'/'full')`로 감싼 블록은 미등록（`admin/config/route.php`）

### 표준판 (Standard)

1. 데모 데이터 실행: `cd admin && php ../scripts/demo_data.php`（멱등, 반복 실행 시 부족한 부분만 보충, 중복 생성 없음）
2. 보조 모듈 데이터량이 적어, 주차/장비/민원/방문객/계약/수입·지출은 데모에서 소량 입력
3. 볼 것: 관리자에 주차 공간/차량, 장비 대장+유지보수, 민원 처리+방문 회신, 방문객 승인, 계약 관리, 수입·지출 관리+통계 추가; 입주민 포털에 내 차량/주차 공간, 주차 기록, 방문객 예약/출입 코드 추가
4. 라우트 차이: `edition_supports('standard')` 그룹 추가, Lite 그룹 유지

### 완전판 (Full)

1. 데모 데이터 실행: `cd admin && php ../scripts/demo_data.php`（멱등）
2. 고급 모듈（결제/승인/투표/쇼핑몰/순찰/안면/그룹/지식 베이스）데모 데이터는 필요에 따라 입력하거나 데모 계정으로 직접 생성
3. 볼 것: Standard 위에 순찰/청소/조경/에너지/직원/알림 템플릿/승인 엔진/결제 주문/투표/SLA/독촉/순찰/쇼핑몰/안면/그룹/지식 베이스 추가; 입주민 포털 활동 신청, 메시지 알림, 투표, 쇼핑몰 주문, 스마트 Q&A, 안면 등록
4. 라우트 차이: 전체 등록, `edition_supports('full')` 그룹 적용（`admin/config/route.php`）

### 버전 전환

```bash
# admin/.env 设置目标版本（逐급累进，full 包含全部功能）
EDITIONS=lite|standard|full

# 重启 webman 生效（容器部署: docker compose restart app；裸机: php start.php restart）
```

- fail-fast 설정: `EDITIONS` 값이 유효하지 않으면 즉시 오류 발생（`admin/config/edition.php`）, 잘못된 버전으로 조용히 폴백하지 않음.
- 데모 데이터 스크립트는 멱등이며, 버전 전환 시 데이터베이스 초기화 불필요; Standard/Full 모듈 데이터는 실제 업무로 입력하면 됨.
