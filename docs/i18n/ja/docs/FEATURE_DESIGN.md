# 機能設計ドキュメント（Feature Design）

> Copyright (c) 2026 erik <erik@erik.xyz> — https://erik.xyz

## 概要

不動産管理システムは**管理画面**（不動産会社社内向け）と**所有者ポータル**（コミュニティの所有者/テナント向け）に分かれ、15 の業務モジュールを 3 バッチで納品します。

---

## 第 1 バッチ：コア業務

### 1. コミュニティ管理 (Community)

**管理画面:**
- コミュニティリスト（検索、ページング、状態フィルタ）
- コミュニティの作成/表示/編集/削除
- コミュニティ情報：名称、住所（省市区）、建築面積、棟数、戸数、開発業者、不動産会社、連絡先電話番号
- 削除はパスワードの再確認が必要、ソフトデリートを使用

**所有者ポータル:** 管理権限は不要、ホームにバインドしたコミュニティ情報を表示。

### 2. 棟管理 (Building)

**管理画面:**
- コミュニティ別に棟リストをフィルタ
- 棟の作成/表示/編集/削除
- 棟情報：名称、タイプ（タワー/板状/別荘/商業）、階数、部屋数、エレベーター数、建築年、構造タイプ
- 並び替え対応

### 3. 部屋管理 (Unit)

**管理画面:**
- 棟別に部屋リストをフィルタ
- 部屋の作成/表示/編集/削除
- 部屋情報：名称、各階の戸数

### 4. 間取りタイプ管理 (RoomType)

**管理画面:**
- 間取りタイプリスト CRUD
- 間取り情報：名称（3LDK）、居室/リビング/トイレ・浴室の数、間取り図

### 5. 不動産管理 (Room)

**管理画面:**
- 建物ツリービュー（コミュニティ→棟→部屋→不動産）
- 不動産の作成/表示/編集/削除
- 不動産情報：部屋番号、フロア、間取り、面積（専有/共有/総面積）、向き、内装、用途（住宅/商業/事務所）、状態（空き/販売済み/賃貸中/自住）
- 所有者の一括バインド/バインド解除

**所有者ポータル:**
- バインドした不動産リストを表示
- 不動産詳細を表示（面積、向き、間取り、権利情報）

### 6. 所有者管理 (Owner)

**管理画面:**
- 所有者リスト（検索、ページング、状態フィルタ）
- 所有者の作成/表示/編集/削除
- 所有者情報：氏名、携帯番号（暗号化）、メール（暗号化）、身分証（暗号化）、性別、誕生日、緊急連絡先、入居日
- 一括インポート（Excel）、一括有効・無効化、一括削除
- 不動産のバインド/バインド解除

**所有者ポータル:**
- 登録（携帯番号+パスワード+認証コード、不動産バインドで検証可能）
- ログイン（携帯番号+パスワード+クリック認証コード、アカウントロック保護）
- 個人情報の表示/変更
- パスワード変更、ログアウト

### 7. テナント管理 (Tenant)

**管理画面:**
- 不動産/大家別にテナントリストをフィルタ
- テナントの作成/表示/編集/削除
- テナント情報：氏名、携帯番号（暗号化）、身分証（暗号化）、賃貸期間、月額家賃、状態

### 8. 料金管理 (Fee)

**料金タイプ（管理画面）:**
- 料金タイプ CRUD：管理費、水道代、電気代、ガス、暖房、駐車料金、修繕積立金、その他
- 単価、課金単位（円/m²/月、円/トン、円/度など）、課金周期（毎月/毎四半期/毎年）、必須かどうか

**請求書管理（管理画面）:**
- コミュニティ/棟/不動産別に請求書を照会
- 請求書の手動作成/編集
- 請求書の一括生成（コミュニティ+料金タイプ+周期を選択し、全不動産に自動生成）
- 請求書情報：料金タイプ、金額、延滞金、料金周期、期限日
- 状態：未払い/一部払い/支払い済み/滞納/免除
- 一括督促通知

**請求書（所有者ポータル）:**
- マイ請求書リスト（状態別フィルタ：未払い/支払い済み/滞納）
- 請求書詳細
- オンライン支払い（WeChat/支付宝、パスワード再確認が必要）
- 支払い記録の照会
- 料金統計（年度・月次トレンド、料金分類の割合）

**支払い記録（管理画面）:**
- 支払い記録の照会
- オフライン集金の登録（現金/カード/銀行振込）

### 9. 修理依頼管理 (Repair)

**管理画面:**
- 修理依頼リスト（状態/分類別フィルタ）
- 修理依頼詳細の表示
- 手配（修理担当者の割り当て）
- 修理進捗の更新

**所有者ポータル:**
- マイ修理依頼リスト
- 修理依頼の提出（不動産、分類、緊急度、説明、画像アップロード、予約時間の選択）
- 修理依頼詳細と進捗の表示
- 修理依頼のキャンセル（待ち手配状態のみ、パスワード確認が必要）
- 修理依頼の評価（1〜5 星 + コメント）

### 10. お知らせ通知 (Announcement)

**管理画面:**
- お知らせリスト CRUD
- コミュニティ別にお知らせを公開
- 分類：通知/お知らせ/リマインダー/イベント
- 固定表示、下書き/公開状態

**所有者ポータル:**
- 公開済みのお知らせリストを表示（分類別フィルタ）
- お知らせ詳細

## 第 2 バッチ：補助業務

### 11. 駐車管理 (Parking)

**管理画面:**
- 駐車スペース管理（番号、地上/地下、面積、状態：空き/販売済み/賃貸中/修理中）
- 車両管理（ナンバープレート暗号化、ブランド、色、タイプ、駐車スペース/所有者バインド）
- 駐車記録の照会（入場/退場時間、滞在時間、料金）

**所有者ポータル:**
- マイ車両リスト
- マイ駐車スペースリスト
- 駐車記録の照会

### 12. 設備管理 (Equipment)

**管理画面:**
- 設備台帳（名称、番号、分類：エレベーター/消防/入退室管理/監視/給排水/給電/空調）
- 設備情報：ブランド、型式、設置場所、設置日、保証満了日、設計寿命
- メンテナンス記録：日常巡回/定期点検/故障修理/大修/交換
- メンテナンス担当者、費用、メンテナンス業者、次回メンテナンス日

### 13. 苦情・提案 (Complaint)

**管理画面:**
- 苦情リスト（タイプ/状態別フィルタ）
- 苦情の処理（処理担当者の割り当て、処理メモの記入）
- フォローアップ登録（フォローアップメモ、満足度記録）

**所有者ポータル:**
- マイ苦情/提案リスト
- 苦情/提案の提出（タイプ：苦情/提案/褒め、分類：サービス/環境/安全/設備/騒音/違法建築）
- 匿名提出、画像アップロード対応
- 処理進捗の表示
- 満足度評価

### 14. 来訪者管理 (Visitor)

**管理画面:**
- 来訪者予約の承認
- 来訪者記録の照会

**所有者ポータル:**
- 来訪者予約（来訪者氏名、電話、身分証、ナンバープレート、同行人数、来訪事由、予定時間）
- 通行コードの生成
- 予約の変更/キャンセル

### 15. 契約管理 (Contract)

**管理画面:**
- 契約リスト（タイプ/状態別フィルタ）
- 契約タイプ：不動産契約/賃貸契約/メンテナンス契約/サービス契約/購買契約
- 契約情報：番号、甲乙方、金額、起止日、締結日、添付ファイル
- 状態：下書き/履行中/満了/終了/更新

### 16. 財務管理 (Finance)

**管理画面:**
- 収入管理（管理費/駐車料金/家賃/広告費/修繕積立金/その他）
- 支出管理（人件費/設備購入/メンテナンス/エネルギー/清掃緑化/事務/税金/その他）
- 収支統計レポート（月次/四半期/年次）

## 第 3 バッチ：高度機能

### 17. 警備巡回 (Security Patrol)

**管理画面:**
- 巡回ルート管理（ルート座標、打刻ポイント）
- 巡回記録（開始/終了時間、所要時間、異常メモ）
- 巡回完了率の統計

### 18. 清掃管理 (Cleaning)

**管理画面:**
- 清掃エリア管理（場所、面積、頻度：毎日/毎週/隔週/毎月）
- 清掃記録（清掃時間、検査担当者、検査メモ、現場写真）
- 清掃完了率の統計

### 19. 緑化管理 (Green)

**管理画面:**
- 緑化エリア管理（場所、面積、主要植物）
- 維持管理記録（散水/剪定/施肥/駆除/補植、費用）

### 20. コミュニティイベント (Activity)

**管理画面:**
- イベント管理（タイトル、内容、分類：文体/祝日/公益/講座/親子）
- カバー画像、場所、最大参加人数、時間、費用
- 状態：募集中/開催中/終了/キャンセル
- 申し込みリストの表示

**所有者ポータル:**
- イベントリスト（フィルタ：募集中/開催中）
- イベント詳細
- 申し込み/申し込みキャンセル

### 21. エネルギー管理 (Energy)

**管理画面:**
- 計器管理（電力量計/水道メーター/ガスメーター/暖房メーター、番号）
- 検針記録（今回の数値、使用量、単価、費用）
- 請求書との自動連携生成

### 22. スタッフ管理 (Staff)

**管理画面:**
- スタッフ情報（氏名、携帯番号暗号化、身分証暗号化、役職、部署、入社日）
- 部署：管理/カスタマーサービス/工務/警備/清掃/緑化/財務
- 状態：在職/退職/休暇

## モジュール横断機能

| 機能 | 説明 |
|------|------|
| ID 保護 | 全インターフェースの ID を hashids エンコードで転送 |
| データ暗号化 | 機密フィールド（携帯/メール/身分証）は API 層 AES-256-CBC、DB 層 encryptable |
| 操作監査 | 全管理者の POST/PUT/DELETE 操作を自動記録、送信元端の自動検出含む |
| 権限制御 | RBAC method.path 粒度、スーパー管理者は * 識別子 |
| レート制限 | Redis スライディングウィンドウ、ログイン 10 回/分、登録 5 回/分 |
| 認証コード | クリック式中国語認証コード、ログイン/登録で必須 |
| ソフトデリート | 所有者、コミュニティ、不動産、お知らせで対応 |
| 国際化 | 中文/英語バイリンガル、PHP symfony/translation + Flutter GetX Translations、デフォルト中文、フォールバック英語 |
| API ドキュメント | `hg/apidoc` 自動生成、58 コントローラ中 57 個が 10 グループにアノテーション（Base/Docs/Install は未グループ）、`/apidoc/config` が設定 API を提供 |
| テスト | TDD フロー、133 テスト/465 アサーション、service 100% 合格、flutter analyze ゼロ問題 |
| Flutter Web | 13 ページ（ログイン/ホーム/料金/修理依頼/個人センターなど）、PC デスクトップスタイル、GetX 状態管理 |
| HarmonyOS | 完全なプロジェクト骨格、ArkTS サービス層 + 認証 + ログイン/ホーム、@ohos.net.http |

## 拡張機能（第 4 バッチ）

### メッセージ通知センター
- 設定可能な通知テンプレート（App プッシュ/ショートメッセージ/メール）
- 請求書リマインダー、修理依頼進捗、お知らせ公開の自動通知
- 所有者端メッセージリスト + 既読管理

### 承認ワークフローエンジン
- 設定可能な承認タイプとステップ（上司→部長→統括）
- 修理依頼の手配/来訪者承認/契約承認は標準化フロー
- 承認記録は追跡可能

### 決済統合
- WeChat/支付宝の決済注文管理
- 決済コールバック処理、返金、照合統計
- 請求書との自動連携更新

### 所有者投票/決議
- 普通投票 + 所有者総会決議（面積加重）
- 選択肢管理、投票記録、自動開票
- 参加率の統計

### 修理依頼 SLA 自動エスカレーション
- 分類+緊急度別に応答/解決期限を設定
- タイムアウト時に上位ロールへ自動エスカレーション
- タイムアウト罰金の自動記録

### スマート督促
- 段階的督促戦略の設定（滞納日数→アクション）
- 滞納請求書を自動マッチングして督促を実行（App/ショートメッセージ/電話/訪問）
- 延滞金の自動計算

### 巡回点検モバイル
- 巡回点検タスクの配信（GPS ルート + チェックポイント）
- モバイル端打刻（位置 + 写真 + 異常マーク）
- 巡回完了率の統計

### コミュニティモール
- 商品カテゴリ/出品/出品停止の管理
- 所有者の閲覧 + 注文 + 注文追跡
- 発送/返金管理

### 顔認証
- 所有者の顔認証登録（第三者認証サービスと連携）
- 管理画面での審査認証
- 入退室管理との連携

### 多コミュニティグループ管理
- グループ→コミュニティの多対多関連付け
- 跨区データ集計（不動産/所有者/料金の統合ビュー）

### スマート Q&A
- ナレッジベース管理（分類/記事/キーワード）
- 所有者の質問の自動マッチング
- 対話記録 + 解決率の統計

### データ大画面
- 全画面リアルタイムの不動産データ可視化
- 料金/修理依頼/設備/エネルギーの 4 大パネル
- 自動スライドリフレッシュ
