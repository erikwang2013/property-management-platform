## 概述

物业管理系统分为**管理员端**（物业公司内部使用）和**业主端**（小区业主/租户使用），覆盖15个业务模块，分3批交付。

---

## 第1批：核心业务

### 1. 小区/社区管理 (Community)

**管理员端:**
- 小区列表（搜索、分页、状态筛选）
- 创建/查看/编辑/删除小区
- 小区信息：名称、地址（省市区）、建筑面积、楼栋数、房屋套数、开发商、物业公司、联系电话
- 删除需密码二次确认，使用软删除

**业主端:** 无需管理权限，首页展示所绑定小区信息。

### 2. 楼栋管理 (Building)

**管理员端:**
- 按小区筛选楼栋列表
- 创建/查看/编辑/删除楼栋
- 楼栋信息：名称、类型（塔楼/板楼/别墅/商业）、层数、单元数、电梯数、建成年份、结构类型
- 支持排序

### 3. 单元管理 (Unit)

**管理员端:**
- 按楼栋筛选单元列表
- 创建/查看/编辑/删除单元
- 单元信息：名称、每层户数

### 4. 户型管理 (RoomType)

**管理员端:**
- 户型列表 CRUD
- 户型信息：名称（三室两厅）、室/厅/卫数量、户型图

### 5. 房产管理 (Room)

**管理员端:**
- 房屋树视图（小区→楼栋→单元→房屋）
- 创建/查看/编辑/删除房屋
- 房屋信息：房号、楼层、户型、面积（套内/公摊/总面积）、朝向、装修、用途（住宅/商业/办公）、状态（空置/已售/出租/自住）
- 批量绑定/解绑业主

**业主端:**
- 查看我绑定的房产列表
- 查看房产详情（面积、朝向、户型、产权信息）

### 6. 业主管理 (Owner)

**管理员端:**
- 业主列表（搜索、分页、状态筛选）
- 创建/查看/编辑/删除业主
- 业主信息：姓名、手机号（加密）、邮箱（加密）、身份证（加密）、性别、生日、紧急联系人、入住日期
- 批量导入（Excel）、批量启禁用、批量删除
- 房产绑定/解绑

**业主端:**
- 注册（手机号+密码+验证码，可绑定房产验证）
- 登录（手机号+密码+点击验证码，账号锁定保护）
- 个人信息查看/修改
- 修改密码、退出登录

### 7. 租户管理 (Tenant)

**管理员端:**
- 按房产/房东筛选租户列表
- 创建/查看/编辑/删除租户
- 租户信息：姓名、手机号（加密）、身份证（加密）、租约起止、月租金、状态

### 8. 费用管理 (Fee)

**费用类型（管理员端）:**
- 费用类型 CRUD：物业费、水费、电费、燃气、暖气、停车费、维修基金、其他
- 单价、计费单位（元/m²/月、元/吨、元/度等）、计费周期（每月/每季/每年）、是否必须

**账单管理（管理员端）:**
- 按小区/楼栋/房产查询账单
- 手动创建/编辑账单（后端接口保留；Flutter 账单页的创建按钮因载荷不完整已移除）
- 批量生成账单（后端接口保留；Flutter 批量生成按钮已移除）
- 账单信息：费用类型、金额、滞纳金、费用周期、截止日期
- 状态：未缴/部分缴/已缴/逾期/豁免

**账单（业主端）:**
- 我的账单列表（按状态筛选：未缴/部分缴/已缴/逾期/豁免）
- 账单详情
- 在线缴费暂未接入支付网关（`POST /service/v1/fees/pay` 固定返回 503，缴费弹窗/按钮已移除），缴费请走管理端支付订单或线下办理
- 缴费记录查询
- 费用统计（年度月度趋势、费用分类占比）

**缴费记录（管理员端）:**
- 缴费记录查询
- 线下收款登记（现金/刷卡/银行转账）

### 9. 公告通知 (Announcement)

**管理员端:**
- 公告列表 CRUD
- 按小区发布公告
- 分类：通知/公告/提醒/活动
- 置顶、草稿/发布状态

**业主端:**
- 查看已发布公告列表（按分类筛选）
- 公告详情

## 第2批：辅助业务

### 10. 停车管理 (Parking)

**管理员端:**
- 车位管理（编号、地上/地下、面积、状态：空闲/已售/已租/维修）
- 车辆管理（车牌号加密、品牌、颜色、类型、绑定车位/业主）
- 停车记录查询（入场/出场时间、停留时长、费用）

**业主端:**
- 我的车辆列表
- 我的车位列表
- 停车记录查询

### 11. 设备管理 (Equipment)

**管理员端:**
- 设备台账（名称、编号、分类：电梯/消防/门禁/监控/给排水/供电/暖通）
- 设备信息：品牌、型号、安装位置、安装日期、质保到期、设计寿命
- 维保记录：日常保养/定期保养/故障维修/大修/更换
- 维保人员、费用、维保单位、下次维保日期

## 第3批：高级功能

### 12. 安保巡逻 (Security Patrol)

**管理员端:**
- 巡逻路线管理（路线坐标、打卡点）
- 巡逻记录（开始/结束时间、时长、异常备注）
- 巡逻完成率统计

### 13. 保洁管理 (Cleaning)

**管理员端:**
- 保洁区域管理（位置、面积、频次：每日/每周/每半月/每月）
- 保洁记录（清洁时间、检查人、检查备注、现场图片）
- 保洁完成率统计

### 14. 绿化管理 (Green)

**管理员端:**
- 绿化区域管理（位置、面积、主要植物）
- 养护记录（浇水/修剪/施肥/除虫/补种、费用）

### 15. 员工管理 (Staff)

**管理员端:**
- 员工信息（姓名、手机号加密、身份证加密、职位、部门、入职日期）
- 部门：管理/客服/工程/安保/保洁/绿化/财务
- 状态：在职/离职/休假

## 面板可视化与导出

### 仪表盘面板

**管理员端仪表盘:**
- 核心指标卡片：应收总额、实收总额、欠费率、入住率
- 费用趋势折线图（月度/季度）
- 费用分类饼图
- 最近操作日志

**业主端首页:**
- 我的房产数量、待缴费金额、最新公告

### Excel 导出

- 业主列表导出
- 账单报表导出
- 缴费记录导出
- 导出时敏感数据自动脱敏

### PDF 导出

- 仪表盘面板可视化导出
- PDF 页头版权 + 页脚不可移除版权水印
- A4 横向布局

## 跨模块特性

| 特性 | 说明 |
|------|------|
| ID 保护 | 所有接口 ID 使用 hashids 编码传输 |
| 数据加密 | 敏感字段（手机/邮箱/身份证）API 层 AES-256-CBC、DB 层 encryptable |
| 操作审计 | 所有管理员 POST/PUT/DELETE 操作自动记录，含来源端自动检测 |
| 权限控制 | RBAC method.path 粒度，超级管理员 * 标识 |
| 限流保护 | Redis 滑动窗口，登录10次/分钟，业主注册5次/分钟（管理端无公开注册） |
| 验证码 | 点击式中文验证码，登录强制（业主端含注册） |
| 软删除 | 业主、小区、房产、公告支持软删除 |
| 国际化 | 中文/英文双语，PHP symfony/translation + Flutter GetX Translations，默认中文、降级英文 |
| API 文档 | `hg/apidoc` 自动生成，admin 10分组 + service 6分组，`/apidoc/config` 提供配置API |
| 测试 | 后端 65 例（admin 43/103 断言 + service 22/42 断言）随仓库分发，Flutter 11 例；CI 覆盖率门槛 admin 1.7%/service 3%，两端 PHPStan 通过，flutter analyze 零问题 |
| Flutter Web | 5个页面（登录/首页/费用/停车/个人中心），PC桌面风格，GetX 状态管理 |

## 扩展功能（第4批）

### 支付集成
- 微信/支付宝支付订单管理（管理端 `POST /admin/payment-order/create` 下单）
- 支付回调处理、退款、对账统计
- 退款必须携带幂等键 `request_id`（≤64 字符），支持部分退款，响应返回累计退款金额
- 在线支付按账单当前未缴金额入账（`credited_amount`），溢缴部分进入自动退款队列；对账会重新入队未退溢缴款
- 账单存在未过期在线支付订单时拒绝线下收款；关联账单自动更新
