# 功能设计文档 (Feature Design)

> Copyright (c) 2026 erik <erik@erik.xyz> — https://erik.xyz

## 概述

物业管理系统分为**管理员端**（物业公司内部使用）和**业主端**（小区业主/租户使用），覆盖15个业务模块，分3批交付。

---

## 第1批：核心业务

### 1. 小区/社区管理 (Community)

**管理员端:**
- 小区列表（搜索、分页、状态筛选）
- 创建/查看/编辑/删除小区
- 小区信息：名称、地址（省市区）、建筑面积、楼栋数、房屋套数、开发商、物业公司、联系电话
- 删除需密码二次确认，使用软删除

**业主端:** 无需管理权限，首页展示所绑定小区信息。

### 2. 楼栋管理 (Building)

**管理员端:**
- 按小区筛选楼栋列表
- 创建/查看/编辑/删除楼栋
- 楼栋信息：名称、类型（塔楼/板楼/别墅/商业）、层数、单元数、电梯数、建成年份、结构类型
- 支持排序

### 3. 单元管理 (Unit)

**管理员端:**
- 按楼栋筛选单元列表
- 创建/查看/编辑/删除单元
- 单元信息：名称、每层户数

### 4. 户型管理 (RoomType)

**管理员端:**
- 户型列表 CRUD
- 户型信息：名称（三室两厅）、室/厅/卫数量、户型图

### 5. 房产管理 (Room)

**管理员端:**
- 房屋树视图（小区→楼栋→单元→房屋）
- 创建/查看/编辑/删除房屋
- 房屋信息：房号、楼层、户型、面积（套内/公摊/总面积）、朝向、装修、用途（住宅/商业/办公）、状态（空置/已售/出租/自住）
- 批量绑定/解绑业主

**业主端:**
- 查看我绑定的房产列表
- 查看房产详情（面积、朝向、户型、产权信息）

### 6. 业主管理 (Owner)

**管理员端:**
- 业主列表（搜索、分页、状态筛选）
- 创建/查看/编辑/删除业主
- 业主信息：姓名、手机号（加密）、邮箱（加密）、身份证（加密）、性别、生日、紧急联系人、入住日期
- 批量导入（Excel）、批量启禁用、批量删除
- 房产绑定/解绑

**业主端:**
- 注册（手机号+密码+验证码，可绑定房产验证）
- 登录（手机号+密码+点击验证码，账号锁定保护）
- 个人信息查看/修改
- 修改密码、退出登录

### 7. 租户管理 (Tenant)

**管理员端:**
- 按房产/房东筛选租户列表
- 创建/查看/编辑/删除租户
- 租户信息：姓名、手机号（加密）、身份证（加密）、租约起止、月租金、状态

### 8. 费用管理 (Fee)

**费用类型（管理员端）:**
- 费用类型 CRUD：物业费、水费、电费、燃气、暖气、停车费、维修基金、其他
- 单价、计费单位（元/m²/月、元/吨、元/度等）、计费周期（每月/每季/每年）、是否必须

**账单管理（管理员端）:**
- 按小区/楼栋/房产查询账单
- 手动创建/编辑账单
- 批量生成账单（选择小区+费用类型+周期，自动为所有房屋生成）
- 账单信息：费用类型、金额、滞纳金、费用周期、截止日期
- 状态：未缴/部分缴/已缴/逾期/豁免
- 批量催缴通知

**账单（业主端）:**
- 我的账单列表（按状态筛选：未缴/已缴/逾期）
- 账单详情
- 在线缴费（微信/支付宝，需密码二次确认）
- 缴费记录查询
- 费用统计（年度月度趋势、费用分类占比）

**缴费记录（管理员端）:**
- 缴费记录查询
- 线下收款登记（现金/刷卡/银行转账）

### 9. 报修管理 (Repair)

**管理员端:**
- 报修列表（按状态/分类筛选）
- 报修详情查看
- 派单（分配维修人员）
- 更新维修进度

**业主端:**
- 我的报修列表
- 提交报修（选择房产、分类、紧急程度、描述、上传图片、预约时间）
- 查看报修详情和进度
- 取消报修（仅待派单状态，需密码确认）
- 评价报修（1-5星+文字评价）

### 10. 公告通知 (Announcement)

**管理员端:**
- 公告列表 CRUD
- 按小区发布公告
- 分类：通知/公告/提醒/活动
- 置顶、草稿/发布状态

**业主端:**
- 查看已发布公告列表（按分类筛选）
- 公告详情

## 第2批：辅助业务

### 11. 停车管理 (Parking)

**管理员端:**
- 车位管理（编号、地上/地下、面积、状态：空闲/已售/已租/维修）
- 车辆管理（车牌号加密、品牌、颜色、类型、绑定车位/业主）
- 停车记录查询（入场/出场时间、停留时长、费用）

**业主端:**
- 我的车辆列表
- 我的车位列表
- 停车记录查询

### 12. 设备管理 (Equipment)

**管理员端:**
- 设备台账（名称、编号、分类：电梯/消防/门禁/监控/给排水/供电/暖通）
- 设备信息：品牌、型号、安装位置、安装日期、质保到期、设计寿命
- 维保记录：日常巡检/定期保养/故障维修/大修/更换
- 维保人员、费用、维保单位、下次维保日期

### 13. 投诉建议 (Complaint)

**管理员端:**
- 投诉列表（按类型/状态筛选）
- 处理投诉（分配处理人、填写处理备注）
- 回访登记（回访备注、满意度记录）

**业主端:**
- 我的投诉/建议列表
- 提交投诉/建议（类型：投诉/建议/表扬，分类：服务/环境/安全/设施/噪音/违建）
- 支持匿名提交、上传图片
- 查看处理进度
- 满意度评价

### 14. 访客管理 (Visitor)

**管理员端:**
- 访客预约审批
- 访客记录查询

**业主端:**
- 访客预约（访客姓名、电话、身份证、车牌号、同行人数、来访事由、预计时间）
- 生成通行码
- 修改/取消预约

### 15. 合同管理 (Contract)

**管理员端:**
- 合同列表（按类型/状态筛选）
- 合同类型：物业合同/租赁合同/维保合同/服务合同/采购合同
- 合同信息：编号、甲乙方、金额、起止日期、签订日期、附件
- 状态：草稿/履行中/已到期/已终止/续签

### 16. 财务管理 (Finance)

**管理员端:**
- 收入管理（物业费/停车费/租金/广告费/维修基金/其他）
- 支出管理（人力/设备采购/维保/能耗/保洁绿化/办公/税金/其他）
- 收支统计报表（月度/季度/年度）

## 第3批：高级功能

### 17. 安保巡逻 (Security Patrol)

**管理员端:**
- 巡逻路线管理（路线坐标、打卡点）
- 巡逻记录（开始/结束时间、时长、异常备注）
- 巡逻完成率统计

### 18. 保洁管理 (Cleaning)

**管理员端:**
- 保洁区域管理（位置、面积、频次：每日/每周/每半月/每月）
- 保洁记录（清洁时间、检查人、检查备注、现场图片）
- 保洁完成率统计

### 19. 绿化管理 (Green)

**管理员端:**
- 绿化区域管理（位置、面积、主要植物）
- 养护记录（浇水/修剪/施肥/除虫/补种、费用）

### 20. 社区活动 (Activity)

**管理员端:**
- 活动管理（标题、内容、分类：文体/节日/公益/讲座/亲子）
- 封面图、地点、最大参与人数、时间、费用
- 状态：报名中/进行中/已结束/已取消
- 报名列表查看

**业主端:**
- 活动列表（筛选：报名中/进行中）
- 活动详情
- 报名参加/取消报名

### 21. 能耗管理 (Energy)

**管理员端:**
- 仪表管理（电表/水表/燃气表/暖气表、编号）
- 抄表记录（本次读数、用量、单价、费用）
- 关联账单自动生成

### 22. 员工管理 (Staff)

**管理员端:**
- 员工信息（姓名、手机号加密、身份证加密、职位、部门、入职日期）
- 部门：管理/客服/工程/安保/保洁/绿化/财务
- 状态：在职/离职/休假

**管理员端仪表盘:**
- 核心指标卡片：应收总额、实收总额、欠费率、入住率

- 缴费记录导出

- 仪表盘面板可视化导出

## 跨模块特性

| 特性 | 说明 |
|------|------|
| ID 保护 | 所有接口 ID 使用 hashids 编码传输 |
| 数据加密 | 敏感字段（手机/邮箱/身份证）API 层 AES-256-CBC、DB 层 encryptable |
| 操作审计 | 所有管理员 POST/PUT/DELETE 操作自动记录，含来源端自动检测 |
| 权限控制 | RBAC method.path 粒度，超级管理员 * 标识 |
| 限流保护 | Redis 滑动窗口，登录10次/分钟，注册5次/分钟 |
| 验证码 | 点击式中文验证码，登录/注册强制 |
| 软删除 | 业主、小区、房产、公告支持软删除 |
| 国际化 | 中文/英文双语，PHP symfony/translation + Flutter GetX Translations，默认中文、降级英文 |
| API 文档 | `hg/apidoc` 自动生成，47个控制器按7分组注解，`/apidoc/config` 提供配置API |
| 测试 | TDD 流程，78个测试/209断言，service 100%通过，flutter analyze 零问题 |
| Flutter Web | 10个页面（登录/首页/费用/报修/个人中心），PC桌面风格，GetX 状态管理 |
| HarmonyOS | 完整项目骨架，ArkTS 服务层 + 认证 + 登录/首页，@ohos.net.http |

## 扩展功能（第4批）

### 消息通知中心
- 可配置通知模板（App推送/短信/邮件）
- 账单提醒、报修进度、公告发布自动通知
- 业主端消息列表 + 已读管理

### 审批工作流引擎
- 可配置审批类型与步骤（主管→经理→总监）
- 报修派单/访客审批/合同审批走标准化流程
- 审批记录可追溯

### 支付集成
- 微信/支付宝支付订单管理
- 支付回调处理、退款、对账统计
- 关联账单自动更新

### 业主投票/表决
- 普通投票 + 业主大会表决（按面积加权）
- 选项管理、投票记录、自动计票
- 参与率统计

### 报修 SLA 自动升级
- 按分类+紧急程度配置响应/解决时限
- 超时自动升级到上级角色
- 超时罚款自动记录

### 智能催缴
- 阶梯式催缴策略配置（逾期天数→动作）
- 自动匹配逾期账单执行催缴（App/短信/电话/上门）
- 滞纳金自动计算

### 巡检移动端
- 巡检任务派发（GPS路线 + 检查点）
- 移动端打卡（定位 + 拍照 + 异常标记）
- 巡检完成率统计

### 社区商城
- 商品分类/上架/下架管理
- 业主浏览 + 下单 + 订单追踪
- 发货/退款管理

### 人脸识别
- 业主人脸注册（对接第三方识别服务）
- 管理端审核认证
- 门禁通行关联

### 多小区集团管理
- 集团→小区多对多关联
- 跨小区数据汇总（房产/业主/收费统一视图）

### 智能问答
- 知识库管理（分类/文章/关键词）
- 业主提问自动匹配
- 对话记录 + 解决率统计

### 数据大屏
- 全屏实时物业数据可视化
- 收费/报修/设备/能耗四大面板
- 自动轮播刷新
